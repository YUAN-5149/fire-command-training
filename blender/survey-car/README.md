# 臺北市消防局 Outlander 勤務車模型（依實車照片，第三代小改款）

依使用者提供的實車照片（前、左右側、後、斜後方共 6 張）製作的臺北市政府消防局
**三菱 Outlander 勤務車**：第三代小改款（2019–2021），車門標示「消防警備車」。
外形依照片與 Outlander 臺灣規格製作，細部仍為近似，不是原廠工程圖。

> 開發過程：第一、二版以為是第四代、也沒有照片，外形不像；第三版改依照片重做。

沿用經驗：`../water-tanker/build_water_tanker.py`（水庫車）與雲梯車腳本
（幾何工具函式、布林切割、徽章貼花、骨架 Empty、攝影棚與算圖設定、GLB 匯出與回讀驗證）。

## 一、交付內容

| 檔案 | 說明 |
|---|---|
| `build_survey_car.py` | 完整建模＋算圖腳本（可重跑重建） |
| `export_glb.py` | 匯出 GLB（含 Draco 壓縮版）並回讀驗證；`SURVEY_PUBLISH=1` 時複製到 `dist/assets/survey-car.glb` |
| `phoenix_emblem.png` | 消防局徽章貼圖（自水庫車沿用） |
| `Survey_Car.blend`、`Survey_Car.glb`、`Survey_Car_draco.glb` | 執行後產生（不進版控） |
| `survey_*.png` | 執行後產生的六張算圖；預覽圖另存於 `blender/preview/survey-car_*.png` |

重跑指令（Windows 工作站）：

```bash
"D:\Blender\blender.exe" -b --factory-startup -P build_survey_car.py
set SURVEY_PUBLISH=1
"D:\Blender\blender.exe" -b --factory-startup -P export_glb.py
```

沒有安裝 Blender 的 Linux 機器可用 `bpy` 套件（Blender 5.1）直接執行 `python build_survey_car.py`、`python export_glb.py`。

快速預覽：`SURVEY_SAMPLES=24`、`SURVEY_PCT=60`、`SURVEY_ONLY=survey_front.png,survey_side.png`；
`SURVEY_ONLY=none` 只建模不算圖；`SURVEY_RENDER_DIR` 指定算圖輸出資料夾。

可改的常數（腳本開頭）：`CALLSIGN`（前擋分隊名，照片為「松江分隊」，預設「信義分隊」）、
`VEHICLE_TYPE`（照片為「消防警備車」，可改「災情勘查車」）、`DONOR`（捐贈字樣，空值即不貼）、`PLATE_NO`（虛構車牌）。

## 三、建模做法

- **兩段放樣**：下車身用明確斷面（`lb_profile`：側面直、腰線處折、底部收圓）沿 X 放樣；
  腰線以上的車廂（greenhouse）另一段放樣，前擋與尾窗斜面由車廂斷面高度變化形成。輪拱用圓柱布林切出。
- **貼在曲面上的零件一律用射線投影**：`Shell` 把車殼建 BVH，`conform()` 把 2D 輪廓切小格投影到車殼，
  `strip()` 做等寬帶，`stick()` 取單點與法線。車窗、窗框、燈、格柵、鍍鉻、徽章、文字都這樣貼。
- 前擋可透視（只留黑色邊框，刪除玻璃下的車殼面），看得到儀表板與方向盤；側窗、尾窗為深色隔熱紙。

### 骨架（動畫用 Empty）

```
Vehicle                       ← 整車行駛（沿 −X 平移）
├─ Steer F L / F R            ← 前輪轉向（繞 Z）
│   └─ Wheel spin F L / F R   ← 前輪滾動（繞區域 Y，負值＝前進）
└─ Wheel spin R L / R R       ← 後輪滾動
```

- 輪轉角 = 行駛距離 ÷ 輪胎半徑 0.352 m。GLTFLoader 會把節點名稱空白換成底線，程式兩種寫法都要接受。
- 紅色燈罩材質名稱 `Red beacon lens` 與水庫車相同，可共用既有的閃爍程式。

## 四、避坑紀錄（沿用自水庫車／雲梯車，及這次新遇到的）

| # | 問題 | 處理 |
|---|---|---|
| 1 | 紅色燈罩發光太強，AgX 會推成粉紅色（水庫車經驗） | 深紅底色＋低發光 0.30–0.35；尾燈第一次用 1.6 又變粉白，已改回 |
| 2 | 尾燈底色和車身紅色太接近，整個看不見 | 尾燈改為深寶石紅＋自身發光，和烤漆區分 |
| 3 | 車尾正對輪廓光，車尾圖過曝（水庫車泵浦特寫同問題） | 車尾兩張圖曝光 −0.7 EV |
| 4 | 字型只找 Windows 路徑，其他機器中文變空白 | 依序找微軟正黑體 → 文泉驛正黑 → Noto CJK，並在 log 印出實際字型 |
| 5 | 實心圓柱輪胎把鋁圈整個蓋住；鋁圈外緣用實心圓盤也蓋住輪輻 | 輪胎改為車床旋轉斷面（中空）；輪圈外緣改為圓環；深色輪圈筒往內退 |
| 6 | 警示燈燈罩被包在燈座外框裡，看不到紅色 | 燈罩本身就是燈條，兩端黑色端蓋 |
| 7 | 車廂與下車身在車尾幾乎重合，算圖出現條紋（z-fighting）；收太窄又在尾窗旁出現紅色平台 | 車尾收窄量取折衷（第三版 0.04 m） |
| 8 | 射線斜掠 D 柱轉角，車窗黑框出現階梯狀 | 後三角窗輪廓退到 x ≤ 1.90，不貼到轉角 |
| 9 | 前擋整片黑底＋玻璃下有車殼，看不到車內與呼號 | 只留邊框，刪除玻璃下的車殼面與下車身頂面 |
| 10 | 車內側板比前擋斜面高，從擋風玻璃穿出 | 側內襯與車頂內襯只做在 A 柱之後 |
| 11 | 後視鏡太寬，超出規格全寬 | 鏡座內移；第三版含後視鏡全寬 2.10 m |
| 12 | 裁切多邊形可能是三角形或五邊形（水庫車經驗） | `conform()` 以扇形三角化，不假設四邊形 |
| 13 | 文字是 FONT 曲線，glTF 不支援（水庫車經驗） | 匯出時轉網格，刪除空網格 |
| 14 | 使用者回饋「很不像」：超橢圓斷面側面圓鼓、沒有肩線，像肥皂 | 改為明確斷面輪廓＋銳利肩線，車身平滑角度 24° 保留折線 |
| 15 | 格柵用粗銀色橫條，看起來像防撞桿；Shield 用細鍍鉻管 | 格柵改黑色細紋＋上緣鍍鉻條；Shield 改寬扁鍍鉻帶 |
| 16 | 十支直輻條不像原廠輪框 | 五組雙輻扁平輻條，亮面輻條配黑色輪圈 |
| 17 | 尾燈只在尾門上、太小；尾窗太寬；缺 OUTLANDER 字樣 | 尾燈加大並延伸到車側；尾窗縮窄；尾門加 OUTLANDER 字樣，臺北市標示縮小移下 |
| 18 | 紅色偏橘粉 | 改為較深的消防紅 |
| 19 | **沒有參考照片就建模**：雲端環境連不到圖片網站，只能憑規格與記憶 | 下次先請使用者提供實車照片（前、側、後），對照照片調整 |
| 20 | 使用者第一次回答「第四代」，但實車照片是**第三代小改款**（頭燈在上、鍍鉻雙橫條、U 形鍍鉻臂、圓形霧燈） | 以照片為準；問車款時直接請對方附照片，比選項可靠 |
| 21 | 照片上車門寫的是「消防警備車」，不是「災情勘查車」 | 依照片；車種名稱放在常數 `VEHICLE_TYPE`，可改回 |
| 22 | 照片車沒有反光條、攝影機桅桿、絞盤 | 全部拿掉；照片沒有的不要自己加 |
| 23 | 後保險桿黑飾板從車尾投影時斜掠轉角，車側出現黑斑；尾窗也在轉角出現階梯 | 尾門面從後方投影只做到 \|y\| ≤ 0.76，轉角改從側面另投一片；尾窗縮小 |
| 24 | 引擎蓋徽章要從車頭方向看才正，圖片軸向和 x/y 不同 | `conform()` 的 `uv` 可傳函式，自行對應貼圖方向 |

## 五、已知限制

- 細部曲面與燈具內部為近似；三菱標誌為簡化的三菱形。
- 車牌為虛構（照片車牌未使用）；分隊名預設「信義分隊」。
- 車門不能開啟；車內為簡化模型。
- 尚未接入網頁場景（演練首頁、信義街景）；接法可比照 `imported-tanker.js`。
