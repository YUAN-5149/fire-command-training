# 災情勘查車模型說明（臺北市政府消防局・Mitsubishi Outlander 車體）

參考對象：臺北市消防局「災情勘查車」——以 **三菱 Outlander（第四代，2022–）** 休旅車改裝，
配備紅色警示燈組、通訊設備、絞盤與災情監視攝影機，可作臨時災害搶救指揮站。
外觀為依公開尺寸製作的比例研究，並非原廠工程圖，也不是依特定一輛勘查車的照片逐一還原。

沿用經驗：`../water-tanker/build_water_tanker.py`（水庫車）與雲梯車腳本
（幾何工具函式、布林切割、徽章貼花、輪拱飾條、骨架 Empty、攝影棚與算圖設定、GLB 匯出與回讀驗證）。

---

## 一、交付內容

| 檔案 | 說明 |
|---|---|
| `build_survey_car.py` | 完整建模＋算圖腳本（可重跑重建） |
| `export_glb.py` | 匯出 GLB（含 Draco 壓縮版）並回讀驗證；`SURVEY_PUBLISH=1` 時複製到 `dist/assets/survey-car.glb` |
| `phoenix_emblem.png` | 消防局徽章貼圖（自水庫車沿用） |
| `Survey_Car.blend`、`Survey_Car.glb`、`Survey_Car_draco.glb` | 執行後產生（不進版控） |
| `survey_*.png` | 執行後產生的六張算圖；預覽圖另存於 `blender/preview/survey-car_*.png` |

重跑指令（Windows 工作站）：

```bash
"D:\Blender\blender.exe" -b --factory-startup -P build_survey_car.py
set SURVEY_PUBLISH=1
"D:\Blender\blender.exe" -b --factory-startup -P export_glb.py
```

沒有安裝 Blender 的 Linux 機器可用 `bpy` 套件（Blender 5.1）直接以 Python 執行，指令同上改為
`python build_survey_car.py`、`python export_glb.py`。

快速預覽（低取樣、縮小、只算指定圖）：

```bash
set SURVEY_SAMPLES=24
set SURVEY_PCT=60
set SURVEY_ONLY=survey_front.png,survey_side.png
"D:\Blender\blender.exe" -b --factory-startup -P build_survey_car.py
```

`SURVEY_ONLY=none` 只建模不算圖；`SURVEY_RENDER_DIR` 可指定算圖輸出資料夾。

## 二、尺寸

| 項目 | 依據 | 本模型 |
|---|---|---|
| 車長 | 消防局車輛大觀約 4.71 m；Outlander 4,710 mm | 4.75 m（含前方絞盤掛鉤） |
| 車寬 | 消防局約 2.19 m（含後視鏡）；車身 1,862 mm | **2.19 m**（含後視鏡），車身 1.86 m |
| 車高 | 消防局約 1.98 m（含燈具）；車身 1,745 mm | **1.98 m**（攝影機頂），車頂 1.745 m，警示燈頂約 1.93 m |
| 軸距／輪距 | 2,705 mm／約 1,600 mm | 2.705 m／1.60 m |
| 輪胎 | 255/45 R20（外徑約 737 mm） | 半徑 0.369 m、20 吋雙色五組雙輻鋁圈（亮面輻條＋黑色輪圈） |
| 座位 | 5 人座 | 5 座（車門標示「限乘 5 人」） |

> 座標系同水庫車：車頭朝 −X、駕駛座在 −Y（左駕）、Z 向上、單位公尺、輪胎底在 z = 0。

## 三、建模做法（與卡車不同的地方）

### 1. 車殼：兩段放樣
- **下車身**：明確的斷面輪廓（`lb_profile`）沿 X 放樣：側面是幾乎垂直的平板，門把高度（約 0.99 m）有一道
  銳利的水平**肩線**，肩線以上內收到腰線，底部圓角收進車底。輪廓用 Chaikin 圓滑，但肩線點保持銳利。
  車頭平面轉角 0.34 m 範圍內縮 0.20 m，引擎蓋前緣約 1.05 m，車頭高而平。
  （第一版用超橢圓斷面，側面圓鼓、沒有肩線，看起來像肥皂，第二輪改掉。）
- **車廂（greenhouse）**：腰線以上另一段放樣，斷面由腰線寬 0.875 m 收到車頂 0.71 m（tumblehome），
  前段是前擋斜面、後段是尾門玻璃斜面。底部埋在下車身裡，交界就是腰線。
- 輪拱以圓柱布林切出，內側加黑色輪弧內襯，外側掃掠方形厚飾條（Outlander 的黑色輪拱）。

### 2. 貼在曲面上的零件：一律用射線投影
- 卡車的車身是平板，零件可以直接算座標；休旅車整個表面都是曲面，手算的曲面公式一定會和實際網格對不上。
- `Shell` 把車殼建成 BVH，`conform()` 把 2D 輪廓切成小格、每個角點射線投到車殼上再沿法線浮起數公釐；
  `strip()` 沿折線做等寬帶；`stick()` 取單點位置與法線放零件。
- 車窗、黑色窗框（B/C 柱黑色「懸浮車頂」）、窗框上緣沿 D 柱下彎的鍍鉻飾條、腰線飾條、車門縫、頭燈、格柵、Dynamic Shield 鍍鉻框、尾燈（延伸到車側）、
  反光條、徽章、文字都用這套方法貼上，所以會貼合曲面。

### 3. 前擋可透視
- 前擋只做黑色陶瓷邊框，並把玻璃下方的車殼面刪除，看得到儀表板、方向盤與車內；
  車頂內襯、側內襯擋住車殼內面。側窗與尾窗為深色隔熱紙（整片黑底），符合公務車外觀。

### 4. 臺北市標示（依水庫車／水箱車慣例）
- 前門：消防局徽章＋「臺北市政府消防局」＋「限乘 5 人」；後門：「災情勘查車」。
- 腰部黃色反光條；尾門「臺北市政府消防局／災情勘查車」。
- 前擋右上（乘客側）黃色呼號 `CALLSIGN = '信義勘查'`——**臺北市勘查車的實際呼號編碼未查到公開資料，此為示意，可改。**
- 車牌 `RFA-1190` 為虛構。

### 5. 勤務裝備
- 車頂紅色長型警示燈（6 格，材質 `Red beacon lens`）、中央兩具白色照明、前方警報器喇叭。
- 格柵兩角、尾門上緣兩側各一組紅色閃光燈（同材質）。
- 車頂後段**災情監視攝影機**（伸縮桅桿＋水平旋轉座＋俯仰球型攝影機）、兩支無線電天線、鯊魚鰭天線。
- 前保險桿下方**絞盤**導纜器與掛鉤。
- 行李廂通訊設備架、監視螢幕與無線電主機（臨時指揮站）。

## 四、骨架（動畫用 Empty）

```
Vehicle                       ← 整車行駛（沿 −X 平移）
├─ Steer F L / F R            ← 前輪轉向（繞 Z）
│   └─ Wheel spin F L / F R   ← 前輪滾動（繞區域 Y，負值＝前進）
├─ Wheel spin R L / R R       ← 後輪滾動
└─ Camera mast                ← 攝影機桅桿升降（沿 Z 平移）
   └─ Camera pan              ← 水平旋轉（繞 Z）
      └─ Camera tilt          ← 俯仰（繞 Y）
```

- 輪子滾動規則同水庫車：`輪轉角 = 行駛距離 ÷ 輪胎半徑 0.369 m`。
- GLTFLoader 會把節點名稱的空白換成底線（`Wheel_spin_F_L`），網頁程式要兩種寫法都接受（同水庫車）。
- glTF 為 Y 向上：Blender 的區域 Y（輪軸）在 GLB 為區域 −Z。

## 五、避坑紀錄（沿用自水庫車／雲梯車，及這次新遇到的）

| # | 問題 | 處理 |
|---|---|---|
| 1 | 紅色燈罩發光太強，AgX 會推成粉紅色（水庫車經驗） | 深紅底色＋低發光 0.30–0.35；尾燈第一次用 1.6 又變粉白，已改回 |
| 2 | 尾燈底色和車身紅色太接近，整個看不見 | 尾燈改為深寶石紅＋自身發光，和烤漆區分 |
| 3 | 車尾正對輪廓光，車尾圖過曝（水庫車泵浦特寫同問題） | 車尾兩張圖曝光 −0.7 EV |
| 4 | 字型只找 Windows 路徑，其他機器中文變空白 | 依序找微軟正黑體 → 文泉驛正黑 → Noto CJK，並在 log 印出實際字型 |
| 5 | 實心圓柱輪胎把鋁圈整個蓋住；鋁圈外緣用實心圓盤也蓋住輪輻 | 輪胎改為車床旋轉斷面（中空）；輪圈外緣改為圓環；深色輪圈筒往內退 |
| 6 | 警示燈燈罩被包在燈座外框裡，看不到紅色 | 燈罩本身就是燈條，兩端黑色端蓋 |
| 7 | 車廂與下車身在車尾幾乎重合，算圖出現條紋（z-fighting） | 車廂在車尾收窄 0.13 m，與下車身保持距離 |
| 8 | 射線斜掠 D 柱轉角，車窗黑框出現階梯狀 | 後三角窗輪廓退到 x ≤ 1.90，不貼到轉角 |
| 9 | 前擋整片黑底＋玻璃下有車殼，看不到車內與呼號 | 只留邊框，刪除玻璃下的車殼面與下車身頂面 |
| 10 | 車內側板比前擋斜面高，從擋風玻璃穿出 | 側內襯與車頂內襯只做在 A 柱之後 |
| 11 | 後視鏡太寬，全寬 2.29 m 超過官方 2.19 m | 鏡座內移，全寬 2.19 m |
| 12 | 裁切多邊形可能是三角形或五邊形（水庫車經驗） | `conform()` 以扇形三角化，不假設四邊形 |
| 13 | 文字是 FONT 曲線，glTF 不支援（水庫車經驗） | 匯出時轉網格，刪除空網格 |
| 14 | 使用者回饋「很不像」：超橢圓斷面側面圓鼓、沒有肩線，像肥皂 | 改為明確斷面輪廓＋銳利肩線，車身平滑角度 24° 保留折線 |
| 15 | 格柵用粗銀色橫條，看起來像防撞桿；Shield 用細鍍鉻管 | 格柵改黑色細紋＋上緣鍍鉻條；Shield 改寬扁鍍鉻帶 |
| 16 | 十支直輻條不像原廠輪框 | 五組雙輻扁平輻條，亮面輻條配黑色輪圈 |
| 17 | 尾燈只在尾門上、太小；尾窗太寬；缺 OUTLANDER 字樣 | 尾燈加大並延伸到車側；尾窗縮窄；尾門加 OUTLANDER 字樣，臺北市標示縮小移下 |
| 18 | 紅色偏橘粉 | 改為較深的消防紅 |
| 19 | **沒有參考照片就建模**：雲端環境連不到圖片網站，只能憑規格與記憶 | 下次先請使用者提供實車照片（前、側、後），對照照片調整 |

## 六、已知限制

- 外形依 Outlander 公開尺寸與一般外觀特徵製作；細部曲面、燈具造型為近似，未取得原廠圖面。
  三菱廠徽未建模（改為一般鍍鉻銘牌）。
- 臺北市勘查車的實際塗裝、呼號編碼、警示燈廠牌未查到公開照片，依臺北市其他消防車輛的標示方式處理。
- 車門、尾門不能開啟（車殼為一體）；車內為簡化模型。
- 尚未接入網頁場景（演練首頁、信義街景）；GLB 已放在 `dist/assets/survey-car.glb`，接法可比照 `imported-tanker.js`。
