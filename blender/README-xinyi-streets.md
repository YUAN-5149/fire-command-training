# 信義區逐街精修（第三階段）

第二階段讓每棟建物都有依分類推定的外觀；本階段**一條街一段一段**對照 Google 街景，
把沿街建物的外觀改成接近實景，並補上官方 LOD1 缺漏的量體。

資料：`dist/assets/building-overrides-xinyi.json`（街景漫遊與 Blender 共用）。

## 每段的做法

1. **列出沿街量體**：取松仁路中心線 70 m 內、有牆面朝路的官方量體，依南北排序，跳過已有精細模型的地標。
2. **街景比對**：每 50 m 一個點，東西兩側各看一次；記下樓層、窗型、一樓（拱廊／玻璃大廳／店面）、主色、
   招牌，名稱以 OSM `name`／地址確認。
3. **寫入精修資料**：每棟一筆，`ids` 對官方量體；欄位說明見 JSON 的 `fields`。
   - `variant` 1 古典石材（拱廊、窄高窗、簷口）、2 玻璃帷幕（豎框、層間帶）、3 穿孔金屬板（圓點板面、窄長玻璃縫）、
     4 預鑄混凝土方格（每格一窗置中、窗洞深凹的陰影框、板縫；臺北市政府）；不設則沿用分類外觀。
   - 官方 LOD1 缺漏時，`footprint` 放 OSM 外框（Douglas–Peucker 簡化 0.8 m）、`height` 放街景估計高度，
     `ids` 用 `osm-<way id>`；街景漫遊會補建牆面、屋頂與碰撞，牆腳高程取 120 m 內官方量體的最低值。
   - 有 `variant` 的建物預設不掛臺式直立招牌（`signs` 可改）。
4. **檢查**：`node tests/xinyi-overrides.mjs`（id 對得到、參數範圍、補建屋頂面積＝外框、法線朝外）；
   街景漫遊在該路段近看；Blender 重跑 `build_xinyi_district.py`，預覽圖 `xinyi-district_songren_n.png`。

## 限制

樓層、窗距、高度都是街景目測推定，非實測；**窗戶不是實際救援開口**。補建量體的高度為估計值。

## Blender 精細立面與屋頂加蓋

`blender/taipei_facade.py`（由 `build_xinyi_district.py` 呼叫）：

- **臨街精細立面**：逐街精修過的老公寓（style 0）與住宅大樓（style 1），其臨街牆（export 標記第 7 欄）改用實際幾何：
  窗洞內凹＋鋁窗框與中梃、窗台、樓板飾帶、女兒牆壓頂；老公寓鐵窗（立柱、橫桿、直條、雨遮浪板）與冷氣機；
  住宅大樓隔間陽台；一樓騎樓（柱、樑、天花、內退店面：鐵捲門或玻璃店面、地坪）與中文店招；直立招牌雙面直排字。
- **屋頂鐵皮加蓋**：依衛星影像，全區老公寓約 85% 屋頂以鐵皮屋覆蓋（灰、白、藍綠、紅褐），水塔墊高到加蓋頂。
- 材質以公尺 UV 貼：二丁掛磁磚（24×6.5 cm）、鐵捲門與浪板波紋、污漬噪聲；EEVEE 開啟光線追蹤與軟陰影。
- 快速試算：`--center LON,LAT --radius M --no-save --no-glb --only <預覽名>`。

## 網站街景漫遊的精細立面與屋頂加蓋

`dist/xinyi-shophouse.js`：與 Blender 同一套規則套到網頁。

- 精細立面只做逐街精修的老公寓／住宅大樓臨街牆（目前 34 棟 86 面牆，約 34 萬頂點）；這些牆不再畫舊的著色器立面，
  也不放舊方塊冷氣／鐵窗／招牌。
- 為了效能：構件只畫看得到的五面；鐵窗直條（鏤空）、鐵捲門與浪板波紋、磁磚縫由著色器畫，遠處以 fwidth 淡出；
  店名用 canvas 文字圖集（橫式 4×8、直式 16×2 格）。
- 屋頂鐵皮加蓋：老公寓約 85%（765 棟、約 11 萬頂點），加蓋高度依建物 id 固定，水塔墊高到加蓋頂。
- 夜間：店面玻璃與招牌發光，約三成窗戶亮燈。
- 測試：`tests/xinyi-shophouse.mjs`。
