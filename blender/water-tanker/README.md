# 水庫車模型說明（臺北市政府消防局 12 噸級水庫車）

參考對象：臺北市消防局現役 **三軸（6×4）12 噸水庫車** 的典型配置
——單排兩門駕駛室、箱型水箱車身、可行走車頂、車頂水砲、車頂硬式吸水管、
車尾泵浦操作盤。外觀為比例研究，並非依特定一輛車的原廠工程圖。

沿用經驗：`../2026-09-13(雲梯車)/outputs/build_aerial_ladder.py`
（幾何工具函式、超橢圓放樣車頭、布林切割、徽章貼花、反光斜紋、輪組、攝影棚）

## 二、尺寸與底盤

| 項目 | 本模型 |
|---|---|
| 全長 × 全寬 × 全高 | **9.51 × 2.50 × 3.48 m**（含後視鏡寬 3.08 m，高度含水砲） |
| 軸型 | 三軸 6×4：前單輪＋後雙軸雙胎（走行樑式 bogie） |
| 前軸 / 後軸 X | −3.20 / 1.80、3.12（後軸距 1.32 m） |
| 軸距（前軸至後 bogie 中心） | 5.66 m |
| 輪胎半徑 | 0.545 m |
| 駕駛室 | **單排兩門**，2.09 m 長，1＋2 人座 |
| 水箱 | **12 噸**（12,000 公升）；車身內可用空間約 15 m³，足夠容納 |

> 座標系同雲梯車：車頭朝 −X、駕駛座在 −Y（左駕）、Z 向上、單位公尺。

## 三、與雲梯車的差異（本次新做的部分）

### 1. 車身
- **單排駕駛室**：沿用超橢圓放樣，車頂提高到 2.98 m，長 2.09 m，每側一門。
  前擋位置改由 `face_x(z)` 依車頭斜度自動計算，不再寫死座標。
- 車頭上緣加白色**銘牌「臺北市消防局」**、格柵兩側紅色警示燈、保險桿警報器喇叭。
- **紅色警示燈條**：臺灣消防車用紅色，不沿用雲梯車參考的歐規藍燈。

### 2. 雙軸後輪拱
- 新寫 `arch_path()`：單軸是半圓；雙軸是「後輪上升 → 頂部直線 → 前輪下降」
  一條連續路徑，輪拱飾條沿它掃掠，車身以兩個圓柱＋一個方塊切出共用輪拱。
- 反光斜紋避讓邏輯改成「輪拱群組」，後雙軸視為一整段。

### 3. 側面
- 前置物櫃（捲門 11 片）、後水帶櫃
- **水位指示燈**（水位 5 格：紅／黃／綠／綠／滅，示意約 8 分滿）
- 大字「臺北市政府消防局」「水庫車」「水箱容量 12 噸」（車身不貼徽章，徽章只在駕駛室）
- 側邊防捲入護欄、車身上緣鋁壓條、車頂邊黃色反光線

### 4. 車頂
- 花紋鋼走道＋可折式護欄
- **車頂水砲**：底座、立管、迴轉環、砲身、整流段、噴嘴、手輪、操作桿
- **人孔蓋**：凸緣、上蓋、鉸鏈、四支旋轉 T 型螺栓
- 通氣管、溢流管
- **硬式吸水管 ×2**：螺旋肋、快速接頭、過濾器、托座與綁帶

### 5. 車尾泵浦操作盤
- 內凹操作艙（捲門已捲起），LED 照明
- 進水／出水壓力錶、引擎顯示幕、指示燈、油門與引水旋鈕
- **中央 100 mm 進水口**（含三耳蓋）＋ **四個 65 mm 出水口**（各附閥桿與洩水閥）
- 中文標示：進水、出水、進水口、出水口
- 紅黃斜紋、右側登頂梯（上端延伸為黃色扶手）、尾燈組、車牌

## 四、依使用者意見修正（第二輪）

1. **車輛代號 51 → 61**：臺北市水庫車代號為 61。
2. **駕駛室改單排**：水庫車多為單排駕駛室（非雙排乘員艙）。駕駛室縮短 0.54 m，
   車身往前加長（車身起點 x −1.74 → −2.28），前置物櫃加寬到 2.36 m，全長不變。
3. **水箱容量標示改為「水箱容量 12 噸」**，字放大。

## 四之二、車頭重做（依實車照片，第三輪）

原車頭是圓鼓鼓的放樣外形、擋風玻璃小、紅框粗、格柵小，看起來像玩具。
改依網路上的實車照片重做：

**參考照片（Wikimedia Commons）**
- [新北市政府消防局永平分隊 Mercedes-Benz Actros 水庫車 AAD-570（永平61）](https://commons.wikimedia.org/wiki/File:New_Taipei_City_Fire_Department_Yongping-61_tanker_in_station.jpg)
  ——Fire Wolf 車體，車門標示「總重28噸／限乘3人」，代號 61 為水庫車
- [臺北市政府消防局大同分隊 五十鈴水箱消防車 KEJ-0662](https://commons.wikimedia.org/wiki/File:TCFD_Datong_Branch_KEJ-0662_left_side_20240823.jpg)
  ——臺北市標示方式：擋風玻璃角落黃色呼號「大同15」，車門「臺北市政府消防局／總重／限乘／車牌」

**改動**
| 部位 | 舊 | 新 |
|---|---|---|
| 車頭外形 | 超橢圓 n=7、大圓角（0.25 m） | n=14、小圓角（0.12 m），幾乎垂直的平面車頭 |
| 擋風玻璃 | 寬 1.88 m、高 0.92 m | 寬 2.06 m、高 0.84 m，幾乎滿寬，黑色外框＋遮陽板 |
| 擋風玻璃下 | 鍍鉻條 | 黑色雨刷飾板，雨刷停在玻璃下緣 |
| 格柵 | 小黑格柵 | 灰色三橫條大格柵（1.72 m 寬）＋中央圓徽 |
| 保險桿 | 黑色圓角塊 | 灰色保險桿，方形頭燈嵌在兩角、霧燈、進氣口，兩側包到灰色登車踏階盒 |
| 警示燈 | 單條紅燈 | 白框分段式紅色長燈條（8 格） |
| 車門 | 徽章＋小字 | 臺北式標示：臺北市政府消防局／總重 26 噸／限乘 3 人／車牌 |
| 代號 | 車身大字 51 | 擋風玻璃右上黃色呼號「信義61」（分隊名可改 `CALLSIGN`） |
| 徽章 | 車門 | 移到車門後方的駕駛室側板 |
| 車身徽章 | 水箱側面大徽章 | **取消**（只保留駕駛室上的徽章） |

> 註：參考照片中的 Actros 為新北市車輛；臺北市水庫車廠牌未查到公開照片，
> 外形取 Actros／Fire Wolf 水庫車的共同特徵，車色維持臺北市的紅色。

## 四之一、算圖調整紀錄

1. 紅色燈罩原本發光太強，AgX 色調映射會把它推成粉紅色 → 改成深紅底色＋低發光（0.35）。
2. 車尾補光太亮造成泵浦特寫過曝 → 補光 2600 → 900 W，泵浦特寫單獨 −1 EV 曝光。
3. 水砲操作桿原本斜向上很長，看起來像天線 → 改為短桿＋垂直握把。
4. 登頂梯原本頂端是兩個圓環 → 改為延伸到車頂的黃色扶手，並避開吸水管位置。

## 七、動畫骨架與動畫

### 骨架（已建在 `Water_Tanker.blend` 裡）

```
Vehicle                         ← 整車行駛（沿 −X 平移）
├─ Wheel spin F L / F R         ← 前輪滾動（繞區域 Y，負值＝前進方向）
├─ Wheel spin R1/R2 L/R outer   ← 後雙軸外胎
├─ Wheel spin R1/R2 L/R inner   ← 後雙軸內胎
└─ Monitor slew                 ← 水砲左右轉向（繞 Z，＋＝往左／駕駛側）
   └─ Monitor elevation         ← 水砲抬頭（繞 Y，＋＝抬高；靜止仰角 14°）
```

- 共 13 個 Empty，重建後外廓尺寸不變（掛骨架沒有移動任何零件）。
- 輪子滾動規則：`輪轉角 = (車位置 x − 起點 x) ÷ 輪胎半徑 0.545 m`，輪胎不打滑。
  驗證：每格地面前進 0.1090 m、胎面轉過 0.1090 m。

### 動畫腳本 `animate_tanker.py`

```bash
"D:\Blender\blender.exe" -b --factory-startup -P animate_tanker.py
```

12 秒、30 fps、360 格：

| 影格 | 動作 |
|---|---|
| 1–150 | 從 15 m 外駛入、減速停車，輪子同步滾動，紅色警示燈閃爍 |
| 165–205 | 水砲轉向右側（−35°）並抬頭 |
| 208–222 | 水柱噴出（拋物線水柱由噴嘴長出） |
| 240–315 | 水砲往左掃（+15°）、再抬高，之後回擺 |
| 330–345 | 停水、水砲回到原位 |

輸出：

| 檔案 | 說明 |

| `Water_Tanker_animated.blend` | 含關鍵影格的動畫母檔 |
| `Water_Tanker_animated.glb` (7.46 MB) / `_draco.glb` (1.69 MB) | 動畫 GLB，14 條軌道合併成單一片段「Drive and monitor」 |
