# 救助器材車模型說明（臺北市政府消防局，車輛代號 71）

## 參考依據

**臺北市政府消防局官網「消防車輛大觀－救助器材車」**
<https://www.119.gov.taipei/News_Content.aspx?n=33BD63446AD2E349&sms=B19BD8864CAC3FA9&s=82ABE6D90516FF23>

- 任務：在災害現場破壞障礙物、為其他救災裝備提供動力，並搭載搶救用裝備。
- 裝置：**發電機組、強力照明燈組、吊臂、空壓機**、各式破壞器材。
- 尺寸：約長 7.5 m、寬 2.5 m、高 3.3 m；車價約 1,200 萬元。
- 官網兩張照片（Mercedes-Benz Atego 底盤、Magirus 車體）顯示的配置：
  - 單排兩門駕駛室；
  - **照明燈塔立在駕駛室後方、駕駛側**，在車體外面，燈頭高過駕駛室車頂；
  - 車身兩側鋁色捲門；
  - **車尾平台上有一具曲臂式吊臂（HIAB 071）**，收車時**沿車寬（橫向）折疊**：
    立柱在右側（乘客側）；內臂從立柱頂端幾乎水平橫跨到左側（駕駛側）的關節，離地約 2 m；
    主昇舉缸躺在內臂下方（紅色缸身、鍍鉻活塞桿朝駕駛側）；
    外臂（貼 HIAB 071 標示）從關節以約 40° 往回斜向上折，末端高過立柱，
    曲臂缸貼在外臂下緣、油管束沿外臂上緣；油壓捲揚機（捲筒＋馬達）在內臂上、靠近立柱；
    兩側各一支支撐腳。

補充參考：
- [新竹市消防局 救助器材消防車](https://119.hccg.gov.tw/chhcfd/app/data/view?module=carIntroduction&id=144&serno=ad97df77-27f9-422b-a05f-a071956f47fc)：
  油壓起重機**裝在車尾、可由兩邊操作**，由昇舉臂和附油壓伸縮臂的屈臂組成，最大伸距 9 m，伸 7 m 以上可吊 1,040 kg。
- [冠軍汽車 救助器材車型錄](https://www.champion-auto.com.tw/tw/html/products/show.aspx?num=694)：曲臂式油壓起重機、LED 照明燈塔、雙層鋁捲門。

> 外觀為比例研究，不是原廠工程圖；吊臂與車身細部為合理推估。

沿用經驗：`../2026-10-24(水庫車)`（平直車頭與單排駕駛室）、`../2026-09-13(雲梯車)`（油壓缸 Damped Track 寫法、匯出流程）。

## 三、配置

**車頭**：沿用水庫車平直車頭，擋風玻璃呼號「**信義71**」（改 `CALLSIGN`）；保險桿中央**前絞盤**（導纜滾輪、鋼索、掛鉤）。

**照明燈塔**：立在駕駛室與車身之間 0.20 m 的空隙（**乘客側**），三道夾具固定在車身前壁，
外管＋兩節伸縮管、黑色螺旋電纜，兩盞黑色投光燈的燈頭在駕駛室車頂上方。

**車身兩側（每側 3 格鋁捲門）**：前櫃、中櫃、輪拱上方延伸到車尾的大櫃；上緣 LED 燈條。
駕駛側前櫃**打開**（車身真的挖 0.70 m 深）：油壓動力組、雙管捲盤、氣墊、擴張器、破壞剪、繩索袋、鏈鋸。

**車身字樣**：捲門上方紅色字帶「臺北市政府消防局　救助器材車」，兩側都依閱讀順序；
車門「臺北市政府消防局／總重 13 噸／限乘 3 人／車牌」。

**車頂**：三節梯（右）、長型工具箱與橘色長背板（左）、護欄、車尾紅色警示燈與工作燈。

**車尾（吊臂平台）**：

## 三之三、第五輪修正（依使用者意見）

1. **吊臂頂端的圓圈改為油壓管**：那是推動伸縮缸的油壓管，不是圓環。
   改成 4 條黑色油壓管，從外臂上緣的油管束在臂端前離開，往上拱過臂端，
   再垂回立柱頂端的閥組（新增「Column head valve」）；油管隨外臂一起動。
2. **駕駛室車頂警示燈改成和水庫車一樣**：白框分段式紅色長燈條（8 格）、
   兩盞巷道燈、車頂天窗、氣喇叭（直接引用水庫車腳本同一段）。
   前一輪的兩顆旋轉燈與警報喇叭已移除。

## 三之四、第六輪修正（油壓管路線、尾燈固定）

1. **油壓管依曲臂吊車的實際配管重拉**（上一輪接到吊頭是錯的）：
   駕駛側操作閥組 → 沿基座上方（管夾固定）→ 沿立柱背面上升 → 立柱頂端閥組（銅接頭）
   → 越過內臂樞軸 → 沿內臂上方（管箍）→ **在關節外側繞一個鬆弛的 U 形彎**（讓吊臂能折）
   → 沿外臂上緣（兩道管箍）→ 進入臂端前的**伸縮缸油口座**。完全不接到吊鉤／吊頭。
   各段分別掛在立柱、內臂、外臂上，吊臂動時油管跟著該段移動。
2. **尾燈不再懸空**：新增全寬黑色**尾燈橫樑**，以兩支吊架固定在大樑尾端；
   尾燈平貼在橫樑後面，下方防捲入桿也掛在同一組吊架上；車牌移到橫樑中間偏左，上方有牌照燈。

## 三之五、第七輪：吊鉤與吊臂動畫（照雲梯車「先頂支撐腳、再動吊臂」）

### 吊鉤
- 吊鉤改成兩層：**Crane hook hang**（臂端滑輪處，Copy Rotation 鎖住整車朝向）→
  **Crane hook lower**（往下放索）。吊臂怎麼仰、怎麼轉，**吊鉤永遠垂直向下**。
- 鋼索 `Hook rope` 以頂端為原點，Z 縮放＝（0.26 m＋放索長度）÷ 0.26 m，鋼索跟著拉長。
- 吊鉤組：黃色吊鉤座＋滑輪、吊鉤軸、吊鉤、安全舌片。

### 為了能真的展開而改的機構
- **曲臂缸改到內臂上方**，推關節銷後方的槓桿（HIAB 的做法）；原本貼外臂下緣的缸，展開超過約 60° 就會拉斷。
  外臂下緣那支改為**伸縮缸**（固定在外臂上，照片中那支細管）。
- 伸縮臂加長到 1.15 m 藏在外臂內，伸出 0.9 m 時仍有重疊，不會出現空隙。
- 油壓管加 Hook 變形：立柱端釘在立柱、關節 U 形彎漸進釘到外臂、基座段釘在車架，
  吊臂展開時油管跟著彎，不會斷開。

### 動畫 `animate_rescue.py`（30 fps、1080 格、36 秒）
| 影格 | 動作 |
|---|---|
| 40–100 | 支撐腳橫樑往兩側伸出 0.30 m |
| 100–160 | 支撐腳往下 0.28 m 到地面 |
| 160–190 | **再頂 25 mm，把車身微微頂起**（腳墊不動，車身上升） |
| 190–275 | 照明燈塔升起（兩節各 1.30 m）；275 起投光燈點亮並追蹤作業點，天色轉暗 |
| 260–330 | 內臂抬起 35° |
| 330–420 | 外臂從上方翻過展開 140° |
| 420–490 | 迴轉 90°，吊臂轉到車尾後方 |
| 490–540 | 伸縮臂伸出 0.9 m |
| 540–610 | 放索 2.0 m（吊鉤約在車尾後 4 m、離地 1.7 m） |
| 610–650 | 停留 |
| 650–1050 | 依相反順序收回：收索、縮臂、回轉、折臂、放下內臂、降燈塔、收支撐腳 |

全程駕駛室紅色燈條閃爍。輸出：
- `Rescue_Truck_animated.blend`（含關鍵影格）
- `Rescue_Truck_animated.glb` / `_draco.glb`（約束逐格烘焙，合併成單一片段「Outriggers and crane」）
- `D:\Claude\救助器材車動畫\rescue_crane_animation.mp4` 與 `frames\`（影片依規定放 D 槽）

```bash
"D:\Blender\blender.exe" -b --factory-startup -P animate_rescue.py
set RESCUE_ANIMATED=1
"D:\Blender\blender.exe" -b --factory-startup -P export_glb.py
```

> 動畫 GLB 限制：油壓管是曲線轉成的網格，GLB 不支援 Hook 變形，所以 GLB 裡關節處油管不會跟著彎（Blender 與影片中正常）。

## 三之六、第八輪：支撐腳空隙、作業照明

### 支撐腳
- **橫向伸出的空隙**：新增 **Stabiliser sliding beam**（滑動橫樑，0.52 m），跟著外殼一起伸出，
  收車時藏在基座內；伸出 0.30 m 後基座與外殼之間仍是連續的鋼樑。
- **往下頂地的空隙**：內腳加長到 1.0 m（鍍鉻油壓桿），全伸時上端仍在外管內，不再露出空段；腳墊加凸台。

### 作業照明
- 燈塔升起後（第 275 格）**兩盞投光燈點亮**：燈面改為發光材質，每盞後面加一支聚光燈（45°、4500 W）。
- **燈頭自動追蹤作業點**：每 5 格計算一次目標（吊臂未伸出車尾前對準臂端，伸到車尾後方後對準吊鉤），
  換算成燈頭旋轉（pan）與俯仰（tilt）打關鍵影格；旋轉角度做連續處理，不會突然轉一圈。
  第 275 格約 −186°／−26°，作業中跟著吊鉤移動，第 880 格熄燈並回正。
- 作業期間棚燈與天空亮度降到 28%（黃昏），照明範圍才看得出來；熄燈後恢復。
- 修正：燈頭俯仰是 **負值朝下**（之前註解寫反，燈會往上照）。

| Jack beam（橫樑） | 鋁色方形 0.26×0.22 m，長 0.60 m，從吊臂基座（兼支撐腳箱）滑出，收車時藏在基座內 |
| Jack leg housing（腳柱外殼） | 鋁色方形 0.30×0.26×0.62 m，頂蓋，外側琥珀色警示燈 |
| Jack leg slide（滑柱） | 鍍鉻方形 0.22×0.18 m，長 0.94 m；伸到底時上端仍在外殼內 |
| 腳墊 | 方形 0.40×0.38×0.08 m，樞軸銷＋兩片夾板，可貼合不平路面 |

動作順序不變：橫樑伸出 0.30 m → 滑柱下放 0.28 m 著地 → 再頂 25 mm 撐起車身。

## 三之九、第十一輪：油壓缸依液壓推頂力學重做

使用者指出伸展臂上的油壓推升桿「沒有根據液壓推頂力學、看起來很空」。問題與修正：

| 問題 | 修正 |
|---|---|
| 伸縮缸兩端都固定在外臂上，活塞桿推的不是伸縮臂，翻過來後像浮在臂上的管子 | **缸身鎖在外臂下方的耳座、活塞桿鎖在伸縮臂頭的耳座**，兩半以 Damped Track 互相對準；伸縮臂伸出 0.9 m 時活塞桿同步伸出（行程 1.50 → 2.40 m，缸身＋桿各 1.25 m 始終重疊） |
| 每支油壓缸的端點只是「頂著」結構 | 昇舉缸、曲臂缸、伸縮缸兩端都加**鍍鉻銷軸＋兩片圓形夾耳＋缸端吊眼**（`clevis()`），力從銷軸傳到結構 |
| 曲臂缸太細，看起來推不動外臂 | 缸身直徑 13.6 → 17 cm、活塞桿 7.6 → 9.6 cm |

力的傳遞：昇舉缸（立柱→內臂下方）抬內臂；曲臂缸（內臂上方→關節後槓桿）把外臂翻開；伸縮缸（外臂→伸縮臂頭）推出伸縮臂。

## 四、汲取的經驗（避免踩坑清單）

| # | 以前踩過的坑 | 本次做法 |
|---|---|---|
| 1 | 沒先查實車就建模（本車第一版漏了吊臂） | 改依**臺北市消防局官網照片與規格**重建，吊臂、燈塔位置、鋁捲門都照照片 |
| 1b | 第二版吊臂憑印象做成「縱向直立折疊」，和照片不符 | 放大照片逐一辨識部件：立柱、內臂、昇舉缸、外臂、曲臂缸、捲揚機，改為**橫向折疊** |

| 4 | 歐規藍燈、紅燈過亮變粉紅 | 紅色燈罩、低發光 |
| 5 | 徽章貼在車窗上 | 徽章在車門後方紅色板面 |

## 五、動畫骨架（已建好）

```
Vehicle                            ← 整車行駛（沿 −X）
├─ Wheel spin F / R L/R ...        ← 車輪滾動（繞區域 Y）
├─ Light mast stage 2 → stage 3    ← 燈塔伸出（沿 Z，每節 1.30 m）
│  └─ Light head pan → tilt        ← 燈頭水平／俯仰
├─ Stabiliser extend L/R           ← 支撐腳橫樑外伸（沿 Y）
│  └─ Stabiliser leg L/R           ← 支撐腳下放（沿 −Z）
└─ Crane slew                      ← 吊臂迴轉（繞 Z，軸在右側立柱）
   └─ Crane inner boom             ← 內臂仰角（繞 X，負值抬起關節）
      └─ Crane outer boom          ← 曲臂展開（繞 X，正值展開）
         └─ Crane extension        ← 伸縮臂（沿區域 Z＝沿外臂方向）
            └─ Crane hook hang     ← 吊鉤懸掛點（Copy Rotation，永遠垂直）
               ├─ Hook rope        ← 鋼索（Z 縮放＝放索長度）
               └─ Crane hook lower ← 放索（沿 −Z）
```

場景自訂屬性：`Axles`、`Tyre radius`、`Mast stroke per stage`、`Crane inner boom pivot`、
`Crane knuckle`、`Crane outer boom stowed deg`、`Crane outer boom length`。

## 六、已知限制

- GLB 內油壓缸是依收車姿勢烘焙的；在 Blender 裡改吊臂角度，油壓缸會自動跟著。
- 只有駕駛側前櫃有內部器材，其他櫃為關閉狀態。
- 車牌 `KEB-7121` 為虛構；吊臂未加任何廠牌標誌。
