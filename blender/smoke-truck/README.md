# 排煙車模型說明（臺北市政府消防局，車輛代號 76）

## 參考依據（先搜尋、後建模）

**臺北市政府消防局官網「消防車輛大觀－排煙車」**
<https://www.119.gov.taipei/News_Content.aspx?n=33BD63446AD2E349&sms=B19BD8864CAC3FA9&s=C776F22C9DEE83B2>

- 定義：於災害現場執行**排煙及送風**任務。
- 裝置：**發電機、引擎驅動排煙機、排煙發泡系統、移動排風機**及其他救災裝備。
- 尺寸：約長 **7.4 m**、寬 **2.45 m**、高 **3.13 m**；車價約 900 萬元。
- 官網照片（存於 `參考圖/`）：
  - `off3.jpg`：**劍潭76（KEG-0626）車尾**，本模型主要依據（放大圖 `off3_zoom_rear.jpg`、`off3_zoom_fan.jpg`）。
  - `off1.jpg`、`off2.jpg`：舊款 Fuso／Fire Wolf 排煙消防車 568-BH，車身寫「排煙消防車」，器材櫃內有**捲收的排風管（外黑內橙）**與**紅色移動排風機**。

從劍潭76 車尾照片辨識出的部件：
| 照片 | 模型 |
|---|---|
| 紅色筒形排煙機，出風口朝車尾 | 筒徑 1.04 m、長約 1.0 m，喇叭口出風 |
| 出風口外圍一圈**灰色折疊風管**，管口有白色硬圈 | 6 道折疊風管（自重微微下垂）＋白色管口圈＋綁帶 |
| 筒內**不鏽鋼噴霧／發泡噴嘴架**：方形管＋四角噴嘴、下方立管、側邊短管 | 方形歧管、4＋2 支噴嘴（銅噴頭），立管穿出筒底接管 |
| 筒內深色、看得到葉片 | 深色內襯、9 片葉輪＋導流整流片 |
| 筒左上**LED 工作燈**（黃色支架）、頂部黃色把手 | 同 |
| 紅色基座，背面**斜紋警示＋花紋鋼護板** | 伸縮臂樞軸座背面同 |
| 基座左下**銅製進水口**＋不鏽鋼蛇腹管 | 65 mm 銅接頭（含扣耳）＋蛇腹管進甲板接頭 |
| 甲板兩側**不鏽鋼工具箱**、右側白色控制盒 | 同（控制盒有指示燈、緊急停止鈕） |
| 車尾中央花紋鋼板＋車牌；兩側紅板斜紋、左上黃字「劍潭76」、左下大字車牌英文、右側大字車牌數字；黃框尾燈 | 同（車牌改虛構 `KEB-7621`） |

**升降機構依據（使用者提供，第二輪）**：自由時報〈雪隧、蘇花改救災利器水霧排煙車宜蘭首度曝光〉照片（`參考圖/yilan_ltn.jpg`）
——Fire Wolf 水霧排煙車，排煙機是用**斜撐的伸縮臂頂升**，不是垂直升降柱：
| 照片 | 模型 |
|---|---|
| 粗大的紅色方形臂，兩節（下段寬、上段較窄插在裡面），從甲板**車尾端**斜向車頭方向升起 | 兩節伸縮臂（外臂 0.30×0.32 m、內臂 0.24×0.26 m），樞軸在車尾迴轉台上 |
| 臂端大型托架（底板＋兩側板）夾住筒身中段 | 托架底板＋側臂＋螺栓固定的耳座，掛在臂端俯仰銷上 |
| 筒前端是**紅色喇叭形進風口**，出風口朝車尾，水霧從出風口噴出 | 喇叭進風口＋防護網；出風口折疊風管＋噴嘴架 |
| 筒頂黑色接頭（油壓） | 4 個油壓快速接頭，2 條油管沿筒側下到臂端旋轉接頭；**風扇由車輛引擎 PTO 油壓驅動**，機頭上沒有獨立引擎 |
| 升起後出風口朝下約 20° | 動畫最後姿勢同 |

劍潭76 收車照片中出風口下方「紅色方塊＋斜紋＋花紋鋼」就是這支臂的**樞軸座**。

使用者另提供臺東、高雄（KEL-2232）同款 Fire Wolf 水霧排煙車作業照片，並指出升降臂是 **Z 字形**：
| 筆畫 | 模型 |
|---|---|
| 下橫：甲板上的臂座 | 迴轉台往車頭方向伸出的**臂托架**（兩根托軌＋橫樑＋墊塊，收車時臂躺在上面） |
| 斜筆：伸縮臂 | 從車尾樞軸斜向車頭升起 65° |
| 上橫：臂端頭臂 | 臂端銷往車尾方向的**頭臂**（兩片側板夾住臂身，焊在托架底板下），把筒體托在臂的後上方 |

照片中另見消防水帶從地面直接接到機頭供水；本模型維持劍潭76 照片的甲板銅進水口＋內部水路。

補充參考：[新竹市消防局 消防排煙車（金山76）](https://119.hccg.gov.tw/chhcfd/app/data/view?module=carIntroduction&id=144&serno=2af7145f-87c1-48f2-bf44-e2b8c3e22ae3)
——EASY 4000 車載排煙機（BMW 雙缸引擎驅動）、排煙量 185,000 m³/h、**升高 1,200 mm、旋轉 360°**、5 支水霧噴嘴；
同為 76 代號，作為車身側面配置（前段捲門櫃、後段開放甲板）的依據（照片 `參考圖/hc_sheet.jpg`）。
日本排煙高發泡車照片（`參考圖/jp_sheet.jpg`）為同類車型旁證。

> 外觀為比例研究，不是原廠工程圖。**劍潭76 的車頭照片查不到**，駕駛室沿用水庫車／救助器材車的平直單排車頭；
> 車身側面依新竹 76 與臺北舊款排煙車推估。

## 三、配置

**車頭**：水庫車平直單排車頭、白框紅色燈條（同系列）；擋風玻璃右上黃色呼號「**劍潭76**」（改 `CALLSIGN`）。**不裝前絞盤**（那是救助器材車的配備）。

**車身（前段，高櫃）**：兩側各 2 格鋁捲門；駕駛側前櫃**打開**（車身真的挖 0.70 m 深）：
上層兩捲排風管（外黑內橙，立放、綁帶）、下層兩台紅色**移動排風機**（防護網、提把、腳輪）。
上方紅色字帶「臺北市政府消防局　排煙消防車」，兩側都依閱讀順序；車門「臺北市政府消防局／總重 11 噸／限乘 3 人／車牌」。

**車頂**：花紋鋼、低護欄（壓在 3.13 m 內）、中央長型備用風管箱。

**車身後壁**（甲板前方）：花紋鋼板、上角工作燈、側標燈。

**開放甲板**（2.35 m 長，跨在後輪上方，同宜蘭照片）：花紋鋼地板、兩側長型不鏽鋼箱、白色排煙機控制盒、排煙機。

**排煙機（可動）**：
| 部件 | 說明 |
|---|---|
| 基座 | 甲板下紅色方箱鎖在大樑上；甲板上迴轉軸承＋迴轉驅動（齒輪箱＋馬達），360° |
| 迴轉台 | 紅色轉盤、兩片側板夾住臂的樞軸銷；背面斜紋＋花紋鋼護板；轉盤下方吊一支迴轉柱伸進基座 |
| 頂升油壓缸 | 缸身鎖在迴轉柱下段（甲板下）、活塞桿鎖在外臂底部耳座，兩端銷軸夾耳，Damped Track 互相對準；收車 0.72 m → 升起 1.13 m，全伸仍重疊 0.24 m |
| 伸縮臂 | 外臂 0.30×0.32 m、內臂 0.24×0.26 m，伸出 0.55 m 時內臂仍有 0.32 m 在外臂裡；外臂口有耐磨墊 |
| 臂端 | 俯仰銷（收車時在筒體前方）＋**油壓旋轉致動器**（乘客側，臂升起時把筒體轉回來保持水平）＋**旋轉接頭**（駕駛側，油路與水路過銷） |
| 頭臂／托架 | Z 字上橫：兩片側板從臂端銷往後上方到托架底板；托架兩側臂＋耳座以 4 顆螺栓固定在筒身中段 |
| 臂托架 | Z 字下橫：迴轉台往前的兩根托軌＋橫樑，收車時臂躺在墊塊上 |
| 筒體 | 紅色喇叭進風口＋防護網、筒身深色內襯、出風口折疊風管＋白色管口圈 |
| 驅動 | 油壓馬達在筒內中心（4 支撐桿），9 片斜角葉片，下游 6 片整流片；筒頂 4 個油壓接頭，2 條油管沿筒側（管夾）到旋轉接頭 |
| 噴嘴 | 方形不鏽鋼歧管＋6 支噴嘴；水路：銅進水口 → 蛇腹管 → 甲板接頭 → 迴轉中心 → 臂內水管 → 旋轉接頭 → 不鏽鋼軟管 → 筒底立管 |

**車尾**：照劍潭76 照片（見上表）；紅色保險桿＋紅色反光條、拖車環。

底盤：PTO 發電機（右側，百葉）、油箱、電瓶箱、儲氣筒、消音器、側防捲入護欄。

## 五、動畫骨架（已建好）

```
Vehicle                       ← 整車行駛（沿 −X）
├─ Wheel spin F / R L/R ...   ← 車輪滾動（繞區域 Y）
└─ Fan slew                   ← 迴轉（繞 Z，360°）
   └─ Fan boom lift           ← 臂升（繞 Y，正值抬起，0–65°）
      └─ Fan boom extend      ← 伸縮（沿區域 −X，0–0.55 m）
         └─ Fan tilt          ← 俯仰（繞臂端銷；臂升 65° 時 −45° ＝出風口下俯 20°）
            └─ Fan rotor      ← 葉輪旋轉（繞 X）
```

操作順序：**先升臂、伸出，再迴轉**（收車時機頭夾在兩側甲板箱之間）。
場景自訂屬性：`Axles`、`Tyre radius`、`Fan slew axis`、`Fan boom pivot`、`Fan boom up deg`、`Fan boom extension`、`Fan tilt level deg`、`Fan drum radius`。

## 七、動畫 `animate_smoke.py`（30 fps、930 格、31 秒）

依操作順序：**先升高、再迴轉、最後才放水送風**；收車反過來，機頭擺正後才降下。

| 影格 | 動作 |
|---|---|
| 1–150 | 從 15 m 後方駛入停車，車輪依行駛距離滾動（不打滑），紅色燈條全程閃爍 |
| 170–260 | 伸縮臂升到 65°，同時臂端旋轉致動器把筒體轉回來（−45°），最後出風口下俯 20° |
| 260–300 | 伸縮臂伸出 0.55 m |
| 300–360 | 迴轉 −60°（出風口轉向駕駛側） |
| 380–430 | 葉輪加速到全速（線性關鍵影格、算圖加動態模糊） |
| 450–620 | **水霧**從噴嘴架噴出（體積霧＋往下游飄的雜訊）；480–600 左右掃一次（−60° → −30° → −60°） |
| 640–690 | 葉輪減速停止 |
| 700–760 | 迴轉回 0° |
| 760–800 | 伸縮臂收回 |
| 800–890 | 臂放下、筒體同步轉回 |

**數值檢查**（每 5 格量機頭所有頂點，不只看畫面）：
- 離車身後壁最近 0.788 m → **OK**
- 進入兩側甲板箱的點數 0 → **OK**
- 筒體最低點 1.992 m（甲板 1.47 m）

輸出：
| 檔案 | 說明 |
|---|---|
| `Smoke_Truck_animated.blend` | 含關鍵影格的動畫母檔 |
| `Smoke_Truck_animated.glb`（7.60 MB）／`_draco.glb`（1.76 MB） | 所有軌道合併成單一片段「Fan lift and slew」；頂升油壓缸（Damped Track）逐格烘焙 |
| `D:\Claude\排煙車動畫\smoke_fan_animation.mp4` 與 `frames\` | EEVEE 預覽 1280×720（影片依規定放 D 槽） |

```bash
"D:\Blender\blender.exe" -b --factory-startup -P animate_smoke.py
set SMOKE_ANIMATED=1
"D:\Blender\blender.exe" -b --factory-startup -P export_glb.py
```

快速檢查：`set SMOKE_TEST_FRAMES=230,330,540,840`（只算這幾格）；`set SMOKE_NO_RENDER=1`（只存檔與跑數值檢查）。

## 網頁版（fire-command-training）

`export_web.py` 讀 `Smoke_Truck.blend`，把每個 rig 節點下的零件合併成一個網格（警示燈罩與舉升油壓缸兩節除外），
輸出 `Smoke_Truck_web_raw.glb`，再用 gltfpack 量化與壓縮：

```
blender -b --factory-startup -P export_web.py
npx gltfpack@0.24.0 -i Smoke_Truck_web_raw.glb -o smoke-truck.glb -kn -km -cc -si 0.6 -se 0.002
```

結果 0.89 MB（原檔 7.9 MB），放在 `dist/assets/smoke-truck.glb`；網頁端以 `MeshoptDecoder` 載入。說明見 `docs/smoke-truck-20261116.md`。
