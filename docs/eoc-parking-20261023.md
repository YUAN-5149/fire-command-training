# 災害應變中心停車場車輛修飾（2026-10-23）

使用者指出應變中心外停車場仍是方塊車。查明該批車輛內嵌於taipei-eoc-core.glb，與道路車流不是同一套模型。

## 已完成

- GLB內共有133個Parked car車輛錨點，每車3個材質子網格（合計399個可繪製網格）。原先由Blender以兩個車身方塊、玻璃方塊與低面數輪胎製作。
- 在信義街景載入地標並貼合地面後，以既有slop圓潤車身及輪圈替代；約五分之一為通用休旅外形，其餘為轎車。此為示意車型，不對應現場品牌或車款。
- 保留所有原車位、原車色及車頭方向。新車以等比例縮放控制在每輛原車的水平包絡內，維持原輪胎接地高度；不移動車格、停車場鋪面、植栽或建物。車位排列仍沿用原模型的示意配置。
- 133個舊車物件保留為來源參照並隱藏，不重複顯示、不處置共用材質或幾何。原GLB檔案與ArcGIS頁的原模型未改；本批為信義街景的顯示替換。
- 使用最多4個InstancedMesh：轎車／休旅各分近、遠兩組。距離45m內切為細模型，超過60m再切回簡化模型；兩級共用原位置及漆色，避免邊界反覆切換。遠處不投車輛陰影，近處保留。
- 相機移動不足1m時不重新分組；車輪固定且車燈維持關閉，不套用道路車流的行車燈或煞車燈。應變中心原有表面細節、夜間亮窗、停機坪燈及風向袋保留。
- 原角色、消防車、公車、道路車流、最新立面與標線保留。

## 檔案與驗證

- dist/eoc-parked-cars.js：辨識舊車、保留位置／朝向／色彩、約束原占地、兩級批次模型與靜止燈光。
- dist/eoc-detail.js及xinyi-street.js：原地標貼地流程後接入，沿相機位置更新顯示級別；入口快取版本parking-20261023。
- tests/eoc-parked-cars.mjs使用實際GLB、旋轉後的地標與傾斜地面，核對133個錨點、全部新車的占地及貼地高度、車頭方向、色彩、冪等替換、數量不重複、距離遲滯、不必要更新略過、靜止輪胎／熄燈，以及夜間建物功能。
- 原tests/eoc-detail.mjs也通過：停車場鋪面、133車、90棵樹、場地貼地、窗戶與停機坪燈等保留。完整回歸由GitHub Actions執行。
