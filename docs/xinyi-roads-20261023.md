# 信義區全區道路與有來源標線（2026-10-23）

使用者要求依實際狀況建置整個信義區道路，包含雙黃線、黃虛線、紅線與斑馬線。本批延續原 GitHub Pages 街景，尚未完成全區現況逐段測繪。

## 已完成

- 從原信義商圈約1×1.7公里範圍，擴充至官方信義區行政界（代碼63002、約11.24平方公里）。完整邊界bbox為121.5525222,25.0081076,121.5921575,25.0495065。
- 20片OSM API圖資去重後，保留行政區內3950段地面道路／人行路徑，3066段在原核心範圍外，新增外圍鋪面。橋梁、隧道、非地面圖層與室內路徑未攤平加入。
- 官方禁停圖資依原座標裁切，新增10519段紅線、730段黃線；數字是裁切後資料線段數，不是道路條數。未為配合推估路幅而移動或吸附官方標線。
- OSM明確標記zebra的100段穿越道供全區斑馬線繪製；只顯示有標記的位置，條紋尺寸為示意。
- 全區地圖、路名及步行／車輛導航使用全區路網，擴大地圖縮放範圍。外圍NPC車流未擴增，避免增加既有動態模擬負擔。
- 整合原本同時出現的兩套推估標線：逐車道路面成功載入時關閉生活層重複標線。原「車道標線」設定改為控制單一推估標線層；官方紅黃線另有開關。
- 紅黃線以400公尺區塊合併，139個可裁切網格、434484個頂點；不新增投影陰影。原模型、車庫、主角、NPC與動作設定保留。
- 核心原官方建物量體、街道JSON、逐車道路面JSON均未覆寫。

## 資料依據與可重建性

- 臺北市交工處禁停紅黃線： https://data.taipei/dataset/detail?id=a9c282c5-3a43-41ed-badc-f9c1bdf1cc34 。下載檔名「禁停紅黃線1130712.zip」，內檔noparkin_202407121525；因此採2024-07-12快照日期。頁面2026-02-03更新日期不代表重新測繪日期。
- 官方公開交通圖台 https://gis.gov.taipei/ 的noparkin SLD圖例核對PATYPE：01禁停紅線、02禁停黃線、06停車場出入口（紅）、11消防紅線、12消防黃線；未知代碼不猜色。SLD原文留在docs/sources/taipei-noparkin-style-20261023.xml。原圖例將消防紅線以洋紅色區別，三維頁依其「消防紅線」名稱呈紅色。
- 行政界： https://data.taipei/dataset/detail?id=1601ef3a-c253-4988-b047-943d9e786143 ，下載檔2022-09-15版本、TWD97/TM2轉WGS84。
- 路網： https://api.openstreetmap.org/api/0.6/map ，4×5小區塊；署名© OpenStreetMap contributors，ODbL1.0。官方資料依政府資料開放授權條款第1版。
- scripts/build-xinyi-road-data.py可由原下載檔重建；下載檔SHA256、每片OSM SHA256及取得時間保留於輸出source欄位。原始城市級ZIP/XML存於本機專案外層，不進公開網站；不匯出編輯者、聯絡人、申請人等欄位。
- 重建：python scripts/build-xinyi-road-data.py INPUT_DIRECTORY --libs OPTIONAL_GIS_LIB_DIRECTORY；需pyshp、pyproj、shapely。輸入名及格式見腳本說明。

## 已驗證

xinyi-road-paint測試：行政區全範圍、來源快照及雜湊、OSM跨片去重、官方分類、有限座標、線段計數、來源欄位限制、400公尺分批、貼地高度、斑馬線超出核心、導航通達西側住宅區、虛線跨節點相位、雙實線成對及資料不變性。純車道數不能觸發新增雙黃線；單行道不能觸發新增對向中線。原GIS斑馬線預設精修範圍行為保持，漫遊頁明確啟用全區。

本機三維幾何建構約0.53秒，這是CPU建模時間，不是實機FPS。既有車庫、角色與NPC另做回歸；完整回歸由GitHub Actions執行。

## 尚未驗證／待辦

- **雙黃線**：原核心osm2streets及舊生活層本來就由路幅／車道數推估；本批去除重疊，但不把原推估升格成現況驗證。需逐段街景、端點與線寬間隔核對。
- **黃虛線**：新取得的全區OSM沒有divider分類，只有12筆lane_markings=yes與40筆no，不能證明哪段是黃色虛線。繪製器支援有明確來源的dashed_line、solid_line、double_solid_line，但本批沒有憑空新增黃虛線位置。
- **紅黃線現況**：圖資為2024-07-12版本；2026現況、線寬、磨耗／補漆、路緣高度需近照與量測。三維顯示寬0.15m不是量測值；官方線段可能與原推估路面邊界不一致，不自動挪動官方位置。
- **道路與斑馬線尺寸**：OSM width可用時保留，否則道路級別或車道數估算；穿越道寬度及條紋0.45m、間距0.9m仍為示意，無實測精度宣稱。地面橋隧與多層道路需另製作立體連接。
- **外圍地形**：沿用核心建物牆腳高程內插，範圍外採原邊界高程延伸。新增地面只為道路貼地顯示，不是DEM，尤其南側山區不能當作真實坡度。
- **外圍建物／細部**：本批只擴道路及標線，外圍逐棟建物、店面、號誌燈桿、停等區、網狀線、出入口及騎樓高差尚未新增現況資料；不加入推測台階或坡度。
- **瀏覽器與效能**：本機HTTP回傳成功；本次瀏覽器自動化工具初始化失敗（kernel assets路徑不存在），無法聲稱已通過實機三維畫面、手機FPS與全區行走視覺驗收。發布後仍需使用者畫面核對。
