# 街道高差、階梯與斜坡建置規則

確認日期：2026-10-27。適用街道、人行道、騎樓、建物入口、廣場、分隊出入口及其步行連接。使用者最新明確指示優先。本規則是建模與互動驗收要求，不是現場測量或法規合格認定。

## 必須保留的需求

街道、馬路與建物之間可能存在路緣、階梯、斜坡及不同地坪高度。不得為了人物好走而將已核實高差全部壓平。**一般可步行階梯應可使用原有走路操作自動逐階上下；可通行斜坡應可連續行走上下，不要求額外按跳躍、爬梯或傳送。** 保留主要操控黃色中隊長；NPC 亦須遵守相同通行條件。

## 資料及模型

1. 每一處高差先建立位置識別、照片日期、來源、上下端與中間平台的平面座標、高程基準、對應建物／道路及信心狀態。照片能確認有階梯，不代表能取得梯高、階數或坡度。
2. 尺寸分開記錄：總高差、每階梯高／踏面深、階數、有效寬度、平台長寬；斜坡上下端高程、水平長度、坡度、橫坡與轉折。未知填「待量測」或 null，不填零、不套用一般建築尺寸當現況。現地尺寸與遊戲通行參數不得混用。
3. 保留官方建物位置、道路走向及原高程基準；同時記錄地理座標與模型本地座標轉換。不可把絕對高程、模型相對高度與視覺防閃爍偏移相加成假的現地高差。
4. 已核實高差可依據資料建模；只知存在但尺寸未核實者列待辦，先做明確標示且可關閉的樣板才可預覽，不能直接當完成實景發布。無依據不補階梯或斜坡，也不移動道路／建物去湊接。
5. 階梯要有連續踏面、立面及必要平台；斜坡要有連續可見坡面、端部與轉折平台。與道路、人行道、騎樓、入口地面對接，不留模型裂縫或重疊面。真實牆、擋土邊界、欄杆及缺口不可因通行而刪除。

## 人物通行與碰撞

1. 高差場景應分開建立「可見模型」「可步行接觸面」「障礙碰撞」「路徑連接」；相互對應，不能只改貼圖、人物整體高度或相機高度。地坪資產非同步載入後須更新通行與碰撞資料，不能要求重新移動或重新整理才生效。
2. 每步檢查行進路徑、腳底支撐、前方階面、頭部淨空及左右邊界。沿已核准階梯逐階自動跨上、踏下；依明列的角色最大跨階高度、可行坡度及下降限制判斷，禁止一次吸附到整層樓、牆頂或不相連的平台。參數須記錄單位、適用角色與測試，不能當作現場尺寸或法規標準。
3. 跨階不可將整座階梯當實心牆擋住；也不能移除碰撞讓人物穿過立面。若使用簡化連續步行代理坡面，必須限定在真實階梯踏步範圍及平台內，對齊上下端高程，保留可見踏步並記錄簡化方式；不得跨越洞口、欄杆或延伸到無階梯位置。
4. 斜坡須連續更新支撐高度及坡向。身體保持自然直立，腳底不得埋地或懸浮；動畫、步速、角色高度及相機平順協調，不用整體地坪抬升或突然傳送掩蓋問題。上坡、下坡、停步、折返及斜向移動都須正常。
5. 須採用與目前腳底高度、所在面及連續路徑相符的支撐面；禁止在多層重疊位置一律選最高面。保留樓梯下方通道，排除屋頂、車頂、樹冠及無法到達的上層面。
6. 過高階差、過陡坡、斷面、封閉入口或淨空不足應阻擋並提示；下行不得瞬移穿地。未製作落下／攀爬機制時，不把懸崖當普通踏階處理，也不自行增加跳躍作為解法。
7. NPC、任務路線、鍵盤、觸控及手把一致遵守通行資料；確認人物能走樓梯，不代表消防車也能走。步行圖可使用已核實階梯／斜坡連接；車輛圖排除階梯，坡道須另有車行依據。
8. 車輛、YouBike、灌木、樹穴、欄杆不得侵占踏步、平台、坡面或入口缺口；景物替換及街道批次更新後重新檢查通行連續性。

## 驗收與提醒

每處使用 [高差建置與提醒範本](templates/street-elevation-review.md) 留存紀錄，至少測試：

- 上行／下行、停在踏步、平台停留、折返、側向與斜向通過、坡道兩端對接。
- 一般走路不按跳躍可自動跨階；跑步不跳過踏步／穿牆；低幀率與不同影格時間不穿透。
- 腳底不埋、不浮、不累積高度漂移；相機無明顯跳動、抖動，走離階梯後恢復原地坪。
- 高階差／陡坡／欄杆／低淨空正確阻擋，重疊樓層不吸到上層，梯下通道保持可走。
- 實際中隊長模型、NPC 路徑、任務操作及輸入裝置；車輛不駛上步行階梯。
- 鄰近植栽、YouBike 與入口不重疊；既有人物貼地及場景回歸通過。瀏覽器目視、實體裝置與幀率未檢查者明列待驗證。

## 目前實作界線

2026-10-27 查閱 dist/xinyi-walk-surface.js、dist/xinyi-street.js 的 updateWalk、dist/xinyi-street-nav.js：已有鋪面高度取樣、人物腳底修正及平面碰撞，但**尚不能據此認定已完成逐階跨步、坡度限制、頭部淨空、多層支撐判斷或階梯專用路徑連接**。目前高度取樣會選高於基底的最高面；未來加入多層地面時必須先修正這個限制。二維路徑連通也不等於實際可上下通行。

本次僅建立規則與可複用範本，未改動運行程式、現場高差模型或宣稱全區已可走階梯。後續每批需分列「已完成」「尚未驗證」「待辦」，通過實作與驗收後再更新本段。
