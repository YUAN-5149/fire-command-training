# EOC YouBike 輪胎與鋪面遮擋修正（2026-10-28）

## 區位與證據
- 依使用者本日截圖，EOC 前方停車列輪胎下緣看似嵌入人行道；圖像為問題證據，並非量測。
- 沿用 eoc-anchor.json、前方模型 x 0–64 / z 0–8，官方站點 500112017、53 柱／18 台示意停放單車，不改任何平面座標。
- 現況分類：遊戲顯示缺陷，非現地地坪改造。實際磚型、寬度、路緣、高程、坡度、樹穴與入口精確尺寸仍待核對／量測。

## 原因與證據界線
- 舊自行車只取中心高度加 2.5 cm，未看前後輪；可重現斜面上最低輪胎穿入約 6.18 cm。這是另外確認的貼地缺陷。
- 真實 EOC 模型／地形測試中，舊輪胎最低仍高於支撐面約 8.33 mm，不能說截圖已證明實體穿地；需同時處理鋪面深度遮擋。
- 本批鋪面覆蓋原用 polygonOffset factor -5 / units -5，且寫入深度，可能將外觀偏移變成景物遮擋。修正為 factor -1 / units -3、關閉覆蓋層 depthWrite，順序為原場景→鋪面細節→YouBike，避免覆蓋層寫出假的較高深度。
- 瀏覽器控制嘗試失敗：failed to write kernel assets（os error 3）。上述是程式與幾何證據，尚未實際 WebGL 目視驗收，不宣稱截圖問題已經目視排除。

## 驗證紀錄
- 通過：前後輪斜面支撐、下半部輪廓不穿地、地坪版本變更、相機不移動時的非同步重新貼地、未刷新時不重算。
- 通過：實際 EOC GLB＋前方鋪面＋lane 地面，18 台單車輪胎最低淨距約 8 mm；全部站點既有道路排除、53 柱與18台車數量保留。
- 通過：人行道覆蓋不寫入深度、YouBike 在覆蓋後繪製；原鋪面幾何與高度不變。
- 尚未驗證：WebGL 截圖前後對照、手機／實機幀率、各時段陰影。
- 上下階、斜坡步行、折返、跑步、NPC、觸控／手把、多層與車輛階梯排除：本批未更動，仍非已驗收功能。
