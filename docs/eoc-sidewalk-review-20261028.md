# EOC／消防局周邊人行道第一批（2026-10-28）

## 區位與證據
- 本批：消防局 EOC 南側既有前方鋪面、東側連接步道；不包含整個信義區或所有周邊廣場。
- 依據：既有 taipei-eoc-core.glb、eoc-anchor.json、2025-01 使用者提供街景對照、xinyi-eoc-frontage.js 前方鋪面。照片只作佈局參考，未匯入 Google 街景影像作貼圖。
- 座標：沿用地標 lon 121.5659615 / lat 25.0287073，heading -1.244°、base 9.66；模型 x 東、z 南，沿用 drapeSite 地形轉換。
- 本地範圍：既有前方 x 0–64、z 0–8；東側既有頂面 x 64–72、z -160–8。這些是原模型範圍，並非實測寬度。
- 現況分類：鋪面存在有照片參考；鋪磚樣式僅外觀試作。灰色錯縫、0.4 m 格子與細縫為遊戲材質參數，不能當作現地磚尺寸。可在設定關閉試作。

## 模型與互動配置
- 僅將原模型頂面三角形作材質細節覆蓋；不用整片矩形跨越路面。每片完整三角形都須通過路網與實際 lane 多邊形排除；無道路資料時不生成。
- 所有覆蓋頂點在既有平面上；防閃爍使用 polygonOffset，不增加可步行高度。原地坪、步行接觸面、碰撞、路徑圖、植物與 YouBike 均保留。
- 一張共用 128×128 生成貼圖、一個繪製網格；無逐磚物件，無新增投影陰影或逐影格重建。
- 支撐面、跨階、坡度、下降、膠囊、淨空及多層支撐：未改動；仍受既有最高面取樣限制。不得據此認定已完成走階梯。
- 中隊長、NPC、任務與車行路徑不改動。一般走路／跑步及車行通過保留原邏輯，操作仍待目視驗證。
- 非同步載入：等 EOC 模型與道路資料皆可用後才建立；近看入口另等人物與 UI 初始化，支援早到與晚到的模型。近看只改相機，不搬移人物；與短草近看互斥。
