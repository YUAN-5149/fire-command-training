# 引用倉庫公車接入（2026-10-23）

使用者要求檢查先前引用的倉庫，若有公車／巴士就接入。查證mrdoob/slop-newyork確實有40呎低地板公車幾何，先前擷取工具只取小客車，因此未進入本站。

## 來源與已完成

- 固定來源：https://github.com/mrdoob/slop-newyork/blob/f98e8da6e9c032dd03be45a1e6b3203ec62aae3d/js/actor-models.js （MIT）。
- dist/vendor/slop/bus-model.js擷取BUS_SPEC、車身、目的地牌與輪胎純幾何；保留原LICENSE。原actor-models.js只新增buildBodyLoft／part／roundedBox匯出，沒有重寫原汽車幾何。
- dist/xinyi-bus.js將原WebGPU/TSL外觀重建為本站WebGL材質，保留車窗、右側前後門、頂部設備、頭尾燈、輪圈等。採通用藍白配色與白色車牌，未使用MTA品牌或紐約路線文字；目的地牌明確標「示意公車　信義街景」。
- 初批最多4輛，保留原116輛汽機車，合計最多120輛。車流密度會一併控制公車數量；沒有合適道路時不生成。
- 公車採全信義區路網獨立候選：primary／secondary／tertiary／trunk，單向路幅至少9m、雙向至少12m，排除已標記的橋梁、隧道或非地面layer；分段長度至少24m。圖資寬度多為估算，這些是示意車流篩選條件，非實測通行認證。原汽機車繼續使用原核心路網。
- 只允許近直行且端點銜接相近的下一段；沒有合適下一段便在路段末端前停等，不隨機跳到其他道路或突然迴轉。未製作真實公車路線、班表、站牌靠站或乘客上下車。
- 公車約12m長、2.6m車身寬，含原鏡桿及車架；碰撞以沿車長排列的9個保守圓近似，玩家、消防車及其他車流均能感知長車身。不是逐網格碰撞，也未為公車拓寬道路。
- 車身與4輪合併為1組實例網格，目的地牌另1組；全部車流合計7組。輪胎隨行進距離轉動，深度材質同步。單台車身加輪胎5604個三角形；4台增加約2.2萬個三角形，未逐台載入模型。
- 設定頁加入公車狀態說明，原車流開關改為「汽車、機車與公車」。保留角色、消防車、車庫、最新立面、網狀黃線及前批效能設定。

## 驗證

新增tests/xinyi-bus.mjs：來源幾何／索引／法線、尺寸及部位、GLSL注入、全車身碰撞範圍、道路篩選與銜接限制、實際建立4輛公車／120車／7批次、輪胎角度、末端停等、密度切換。全區路網有151個符合寬度與道路等級初篩的feature；實際車流另剔除短路段。汽機車模型、街道生活層與效能測試通過；完整回歸由GitHub Actions執行。
