# GitHub 樹木外觀更新（2026-10-27）

## 已完成

- 調查 GitHub 樹木資源後選用 dgreenheck/ez-tree，固定版本 dcf309bd86bd521083d9c70f01f2de45fdc7c457。程式與葉片圖 MIT，樹皮 ambientCG Bark001 為 CC0；原授權、貼圖授權與素材 SHA-256 均保留。
- 三種分枝樹形（寬冠、擴展冠、直立冠），含漸細樹幹、次級分枝、帶透明輪廓的葉片卡與樹皮紋理，取代實心棉花團樹冠。這些是通用樹形，不是臺灣樹種實測模型。
- 共用幾何約1.5MB，貼圖縮至512px。每種提供三層細節，近處完整、中距與遠處簡化；低／中／高品質使用不同顯示距離，離開範圍即不繪製。最多18個批次，不為每棵樹載入獨立模型，也不加入逐葉動畫或新增樹木陰影計算。
- 沿用528筆行道樹位置、既有補植樹位置及EOC原有90棵樹位置／底部高度。以新模型覆蓋舊樹冠，近距重複的舊樹位只顯示一棵；保留全部來源記錄。EOC模型不改寫，未擴張綠地或調整照片柱列配置。
- 新幾何與兩張貼圖成功載入後才隱藏舊樹；失敗保留原樹作備援。沿用樹木顯示開關及品質設定；保留人物貼地、跑步、小地圖、YouBike與共同編輯者最新內容。

## 驗證

使用 Blender 以實際幾何及貼圖渲染三種模型素材預覽（位於工作區父資料夾，非遊戲畫面）。測試檢查三層面數下降、幾何／UV／索引有效、透明葉材質、保留原樹位、真實EOC GLB替換／不累積重複樹、顯示距離與遲滯、品質及隱藏時停止更新。完整CI執行既有場景回歸。

## 尚未驗證與待辦

- 瀏覽器 WebGL 成像、設備FPS及實際移動體感待驗收；素材預覽不等於遊戲截圖或效能測試。
- 現地樹種、逐棵實際高度／樹冠寬度、季節與修剪情形未調查。新模型改外觀，沿用位置及既有尺寸，不宣稱實景掃描復原。
- 後續可依近照調整應變中心的疏葉／修剪狀態，以及個別臺北常見樹種輪廓。
