# 茂密樹形與指定樹種外觀（2026-10-27）

## 已完成

- 新增六種茂密一般樹形：圓頂、傘冠、直立、低冠、展冠、團簇，增加分枝、葉叢與葉片面積，非單純把原樹放大。與原六種一起沿既有樹位穩定混合，不新增或移動樹位。
- 新增櫻花樹、小葉欖仁、榕樹、台灣欒樹四種示意外觀。櫻花有獨立粉紅花瓣；小葉欖仁為五層水平輪生枝與葉冠；榕樹增加十八組近距垂落氣根；台灣欒樹有獨立黃花簇與紅色三稜蒴果，不把紅果當紅花。
- 在設定的樹木外觀選單提供六種新茂密樹形及四種樹種預覽，可恢復原樹位混合樣式。預覽會保留原錨點並縮放至原樹冠包絡；不影響三種灌木、45 叢植栽島或 YouBike 修正。
- 預設混合只用十二種一般樹形，不把四種指定樹種任意指派到未確認街樹。網址參數 trees=cherry、terminalia、banyan-species、taiwan-goldenrain 可開啟明確標示的樣式預覽。這是整體樹形預覽，不是逐點現況認定。
- 三層細節、批次實例、移動節流、品質與顯示開關保留。茂密樹最高細節距離低／中／高品質為25／40／55m。單株近距最高23,083三角形，花果數量有限制；未增加逐葉動畫或陰影。遠距葉片限制在近距包絡，不穿入地面。
- 新素材目錄 dist/assets/plants-ez-v3/。幾何原始約14.73MB，優先下載約8MB gzip；不支援解壓或壓縮檔載入失敗時讀原始檔。舊v2素材保留供舊頁快取。

## 驗證

十九種植栽模型（十六種樹木、三種灌木）的三層幾何、有限數值、UV、索引、地面界線及遠距預算；四種預覽原位置及包絡、灌木不變、重設不漂移、壓縮與原始資料一致、EOC真實GLB替換與人物地坪、YouBike道路檢查。

## 尚未驗證與限制

四種樹為形態與季節示意，仍共用原已授權的泛用橡樹葉叢貼圖，非植物學精密葉形或照片級掃描。櫻花品種未指定；花果為固定展示狀態，不宣稱同時期全區現況。實際街樹品種、花期、逐株尺寸待照片／調查核對。遊戲實際WebGL外觀、幀率與實體手機操作仍待驗收；獨立Blender模型預覽不是遊戲畫面。
