# 救助器材車「信義71」模型（2026-11-16）

新增臺北市政府消防局 71 救助器材車 3D 模型，接入**消防演練首頁（富錦街）**與**信義街景漫遊**。
既有車輛、車組、雲梯、排煙車與分隊流程不變；救助器材車不屬於四個車組。

## 模型與容量

- `dist/assets/rescue-truck.glb`：**0.85 MB**（Blender 原始匯出 8.2 MB）。車頭朝 -X、公尺、輪胎底在 0，與水庫車、排煙車同慣例。
- 外觀依消防局官網「消防車輛大觀－救助器材車」9E-621 的兩張照片：單排駕駛室、鋁捲門器材箱（駕駛側前櫃打開，可見油壓破壞器材）、
  **後置曲臂式吊臂**（HIAB 071 級，收車時橫向折疊）、乘客側照明燈塔、前絞盤；支撐腳採雲梯車同款方形箱型結構；
  吊臂捲揚機、黑色伸縮臂、紅色吊鉤依救助分隊吊臂照片。車牌虛構。
- 網頁版處理（`blender/rescue-truck/export_web.py` + gltfpack 0.24，同排煙車）：
  1. 同一 rig 節點下的零件合併為一個網格（每種材質一個 primitive）：約 650 個網格 → **30 個**；
     紅色警示燈罩依左右各合併成一個（左右交替閃爍），三組油壓缸六節、吊鉤鋼索、捲揚機鋼索保持獨立。
  2. `gltfpack -kn -km -cc -si 0.6 -se 0.002`：頂點量化（KHR_mesh_quantization）、meshopt 壓縮（EXT_meshopt_compression），
     簡化誤差上限 0.2%；外廓與原檔相同（7.985 × 3.080 × 3.712 m，含前絞盤掛鉤、吊臂捲揚機、後視鏡與收車的燈塔燈頭）。
- 解碼器與排煙車共用 `dist/vendor/jsm/libs/meshopt_decoder.module.js`，不另外下載。

## 吊臂 rig（`dist/imported-rescue-truck.js` 的 `rigRescueCrane`）

`set(u, slew)`：u 0 收車 → 1 作業，依實際作業順序（先穩車、再動吊臂）：

| u | 動作 |
|---|---|
| 0–15% | 支撐腳橫樑外伸 0.30 m |
| 15–28% | 滑柱下放 0.28 m，腳墊著地 |
| 28–42% | 燈塔兩節各升 1.30 m，燈頭轉向車尾並下俯 25° |
| 42–54% | 內臂抬起 35°（昇舉缸伸長） |
| 54–72% | 外臂從上方翻開 140°（曲臂缸推關節後方槓桿） |
| 72–84% | 迴轉到 slew（0° 駕駛側、90° 車尾、180° 乘客側） |
| 84–92% | 伸縮臂伸出 0.90 m（伸縮缸同步伸長） |
| 92–100% | 放索 2.0 m |

glTF 沒有 Blender 的約束，以下每次姿勢改變都在 JavaScript 重新計算：三組油壓缸兩節對準另一端銷；
吊鉤懸掛點重設為與車身同向（吊鉤永遠垂直）；鋼索依放索長度伸長；捲揚機鋼索對準臂端並伸長。

## 消防演練首頁（`index.html` → `app.js`）

- 不等救助器材車載完才開場，背景載入後才加入場景與警示燈閃爍；載入失敗時略過。
- `dist/staging.js`：`rescueTruckStaging = {x:33, z:14.6, heading:π/2}`。原車道已沒有空位，停在對向側車道東段、順向（與排煙車左右對稱），
  佔 x 29.15..36.85、z 13.35..15.85，在道路範圍內，不占雲梯作業區。吊臂收車。
- `index.html` 的 `app.js` 版本改為 `?v=rescue-20261116`。

## 信義街景漫遊（`xinyi-street.html` → `xinyi-street.js`）

- `dist/xinyi-street-rescue-truck.js`：`RESCUE_TRUCK` 參數與 `createRescueTruck`，沿用水庫車的出勤、行駛、停車與避讓邏輯（`createTanker` 的 spec）。
  派遣火警後出勤準備 45 秒，自信義分隊車庫前出口出車，停在火場 12–45 m 的車道（順向）；
  停妥後 30 秒內依上表展開，吊臂迴轉朝向火場。吊臂只在車尾半圈迴轉，不越過車身。不載水、不補水。
- `xinyi-street.js` 接線：背景載入（失敗不影響其他功能）；派遣（排在排煙車之後、水庫車之前選停車點）、結束任務收回、
  碰撞圓與其他支援車的停等障礙；分隊指揮面板（B）增加狀態列（出勤準備／行駛中／架設支撐腳、展開吊臂／吊臂與照明就位）；
  任務紀錄 JSON 增加 `rescueTruck`；`window.__xinyiStreet.rescueKit`。
- `xinyi-street.html` 的 `xinyi-street.js` 版本改為 `?v=s69-rescue-20261116`。
- 本機實測：派遣後 174 秒到場、204 秒吊臂與照明就位，迴轉 133° 朝向火場，主控台無錯誤。

## 測試

- `tests/rescue-truck.mjs`（加入 CI）：檔案 < 1.2 MB、壓縮擴充、網格數 ≤ 32、rig 節點與警示燈材質；meshopt 實際解碼後檢查外廓；
  收車／作業（朝車尾、朝乘客側）時三組油壓缸對準兩端銷、吊鉤垂直、捲揚機鋼索對準臂端；作業時腳墊著地、昇舉缸伸長、
  伸縮缸隨伸縮臂伸長 0.9 m、吊鉤轉到車尾後方、燈塔升起；收回後回到原位；
  首頁停放位置不與車組、水庫車、勤務車、排煙車、雲梯作業區重疊；方格路網上出勤 → 行駛 → 停妥 → 展開，不補水，結束任務後收回。

## 限制

- 吊臂關節處的油壓管在網頁版是固定形狀（Blender 中以 Hook 變形跟著彎），外臂翻開後關節處油管不會跟著彎。
- 作業照明（投光燈點亮、追蹤吊鉤、黃昏光線）只在 Blender 動畫中，網頁版燈頭只轉向車尾、不發光。
- 出勤時間、車速、停車點、展開時間皆為示意，不是實際派遣規定或車輛性能。
