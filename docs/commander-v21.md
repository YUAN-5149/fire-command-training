# 中隊長角色 v21 整合（2026-10-16）

依使用者指示，以已精修的黃色消防娃娃取代黃色中隊長，沿用既有靜態網站與 Three.js 186。

## 資產

- `dist/assets/commander-firefighter-v21.glb`（33,978,784 bytes）。
- 來源：使用者本機「黃色消防娃娃-揮手避開頭盔-v21.glb」，內容原樣上傳；Blender 工作檔仍保留於本機。
- SHA-256：`cd2d368f352e3ec0f6dc1e57031c22f94bd65661a952438f02ea7047724be7c7`。
- 保留 Idle、Welcome、Wave、Point 四段骨架動畫；可由角色的 `playAnimation(name)` 呼叫。
- 保留右側 FIRE CAM、護頸片、氣瓶背架、完整束帶、圓環反光袖帶及手套造型。裝備為角色外觀模型，非實裝工程規格。

## 接入方式

- `commander-character.js` 使用共用 GLTFLoader 快取與 SkeletonUtils.clone，讓各人物保有獨立骨架。
- 適用原演練首頁「人員近看／控制中隊長」及信義街景漫遊中的黃色中隊長；其他階級仍使用原模型。
- 對齊場景高度 1.8 m、面向 -Z，並維持舊角色鞋底的地面高度。
- 保留同步 createPerson API；載入成功才替換原外觀，失敗時保留原角色與控制。
- 保留既有手臂、腿部控制介面；將步行擺動套到新骨架，水線瞄準時將瞄子放到實際右手。
- 原網站未新增揮手／指向按鈕；四段動畫隨 GLB 一起保存，原有行走仍由場景控制。
