# 信義街景流暢度調整（2026-10-23）

使用者反映人物動態移動卡頓。本批減少每幀背景工作，保留玩家行走2.6m/s、跑步6m/s、原肢體擺動頻率、角色資產及場景內容。

## 已完成

- 小地圖由每個繪製幀重畫改為約10Hz；步行／駕駛／室內切換立即刷新。人物輸入、物理移動與相機仍逐幀更新。互動提示亦約10Hz更新，互動距離判定仍使用即時座標。
- 116輛背景車的避障由全車配對掃描改為32m網格鄰近查詢；維持原30m精確篩選、間距、煞車及讓道判定。每輛移動後即更新索引，跨格及同幀後續車輛使用目前位置。關閉車流時不再上傳其instance矩陣。
- 玩家中隊長、40m內角色及持水線角色保持逐幀骨架更新；其餘角色按距離約20/10/5Hz更新骨架，根節點移動與碰撞仍每幀計算。分隊待命、登車／下車、跟隨與借用雲梯車人員流程保留。隱藏角色停止骨架排程，顯示時不累積隱藏時間。
- 角色骨架復用已更新的父矩陣，避免取得關節旋轉時反覆更新祖先；瞄子隱藏時略過手部換算，顯示時仍貼合真實手部。移除多餘的整棵角色矩陣重算，保留鞋底界限與骨架更新。
- 自動畫質的像素倍率最高1倍，降低高DPI裝置填色負擔；手動低／中／高設定保持原倍率。自動模式以原始牆鐘幀時間判讀，避免物理步長上限把低FPS誤報為20FPS；約2.5秒觀察後依負荷降低一級。未強制覆寫已儲存的手動畫質或幀率。
- 頁面隱藏時停止模擬／繪製，重新顯示不追補背景時間。原暫停及地圖選單行為保留。

## 驗證

- 新增tests/xinyi-performance.mjs：30/60/144Hz下的小地圖排程、真實15FPS取樣、暫停間隔、近／遠角色排程及累積動畫時間、車輛跨格與密度切換的一致性。
- 合成分散116車案例：附近候選比對6,150次，原全掃160,080次，減少約96%；此數據是合成查詢量，不是實際FPS或整站加速倍數。
- 角色四種實際GLB、獨立骨架、走路、手勢、瞄子、鞋底與fallback，以及原車流／道路與分隊人員登車跟隨回歸通過。完整回歸交由GitHub Actions。

## 尚未驗證

瀏覽器檢測工具無法啟動（kernel資產路徑錯誤），本批沒有取得實機GPU／FPS量測或操作錄影，不能承諾固定幀率。遠處骨架會較低頻，靠近40m內即恢復逐幀；全區建物及高精度角色的GPU負擔仍存在，低效能裝置可使用既有低畫質。部署後核對HTTP版本與程式資源，實機體感待使用者試走。
