# 汽機車外觀細修（2026-10-23）

使用者記得已導入其他GitHub車輛模型，但仍覺得方正，並要求改善機車。本批延續現有車流，沒有重建網站或更換消防車。

## 查證與已完成

- 既有轎車、休旅車、計程車與警車確實使用mrdoob/slop-newyork的MIT放樣車體，並非仍全部使用方塊汽車。版本為0049a497be6e36c79f854771f3018f8f41f07fab；保留dist/vendor/slop原檔及LICENSE。來源：https://github.com/mrdoob/slop-newyork 。既有WebGL材質是slop-webgl.js。
- 機車仍是BoxGeometry車殼、方塊輪胎及簡化騎士，現已改為本地程式建立的踏板車：圓潤後車殼、前腿盾、階差踏板、座墊、圓形輪胎／輪圈／輪輻、薄土除、前叉、後照鏡、排氣管、頭尾燈與白色車牌。
- 騎士有坐姿骨盆、彎曲手臂與腿、握把上的手、鞋、安全帽及面罩；為一般示意騎士，未修改消防員角色。
- 汽車由原設計表複製本地細修設定，降低肩線超橢圓指數、圓化車頂截面、略增加曲面取樣並補立體五輻輪圈。保留原車型、計程車頂燈、警車塗裝、車燈／窗框／門縫等既有材質。
- 汽機車輪胎隨行進距離／半徑轉動，使用每實例wheelRoll在頂點著色器處理；深度材質同步，避免拆成逐輪物件。煞車及夜間頭尾燈仍更新。
- 116輛背景車維持原車道、尺寸規格、密度、空間索引、避障與鳴笛讓道；機車長度不超過原1.8m範圍。每車種一個InstancedMesh，原4組汽車＋3組機車共7組，現在5組。每幀新增一個輪轉角屬性更新，未逐車新增模型載入或碰撞物件。
- 保留前批小地圖節流、角色更新與自動畫質減負荷設定，並更新快取版本。

## 檔案與驗證

- dist/xinyi-traffic-models.js：本地車體細修與機車／騎士、材質、輪胎及深度著色器。無外部新增模型下載。
- dist/xinyi-street-life.js：五種車流接線、顏色、煞車及輪轉角，已移除早期方塊fallback。
- tests/xinyi-traffic-models.mjs：有限幾何與法線、索引、原車規格不變、原vendor表不變、圓輪／騎姿尺寸與燈光屬性、著色器注入、實際建立116輛車、5組批次、轉輪方向、密度及日夜控制。
- 三角形數：轎車4688、休旅4702、計程車4816、機車含騎士5836。警車共用轎車外形；材質保留警車配色。
- 既有slop車輛、車道生活層與效能排程測試通過。完整回歸由GitHub Actions執行。
- 本機以匯出幾何產生多角度軟體預覽並目視檢查；該圖只是幾何檢視，沒有模擬完整GLSL車窗、燈光或遊戲畫面。

## 尚未驗證／限制

瀏覽器檢測工具目前無法啟動，本批未完成實機WebGL編譯、遊戲截圖或FPS量測。新增模型比舊機車有較多三角形，即使批次數降低，也不能據此宣稱GPU一定更快；低效能裝置仍需實測。車輛為通用示意外觀，未對應特定臺灣品牌或真實車牌；轉向仍使用原車身朝向，沒有新增前輪轉向／懸吊物理。
