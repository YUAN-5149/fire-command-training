# YouBike 車道錯置修正（2026-10-27）

## 原因

官方資料提供站點代表座標與容量，未提供逐柱位置。舊程式依最近道路切線推估朝向，以容量自動產生一至多排車柱及 65% 示意車輛，未檢查完整自行車佔地與車道的重疊。先前測試只驗證點位、容量、貼地與數量，沒有驗證車輛是否在路外；EOC 測試的「位於鋪面」也不能證明沒有與道路重疊。

## 本批處理

- 保留 129 站官方代表座標、站名及 4,372 柱容量資料；停止把容量直接轉為未核對實體車列。128 站只保留地圖站點、查詢與導航，不再生成猜測排列或立在路中的 3D 站牌。
- EOC 照片配置保留 53 柱、18 輛示意自行車；通過目前模型的車道與完整車身邊界檢查，仍非逐柱實測。
- 道路檢查涵蓋全區路網寬度走廊，以及實際車道、路肩、公車道、自行車道、施工車道與路口多邊形。檢查柱體、每柱預留自行車範圍及站牌；即使是空柱也檢查停車後車尾範圍。任何重疊整站暫停實體顯示，不把車列強推到另一側或任意挪官方座標。缺道路資料亦不核准實體排列。
- 舊 EOC GLB 的 YouBike 示意仍由現有去重流程隱藏；Blender 產生／匯出流程已查閱，其餘建物、場地與車輛不改動。
- 介面區分官方容量資料與已核對配置，不再宣稱全區已呈現完整實際柱位。

## 全站稽核

129 站自動候選配置中，88 站與模型道路範圍重疊。這是程式產生配置的問題指標，不是指官方站點或現場站體設於路中；路寬有推估資料，未碰撞也不等於現況正確。其餘 40 站無照片配置依據，同樣暫不顯示實體；EOC 1 站保留照片配置。

可重跑：`node --no-warnings --experimental-loader ./tests/three-loader.mjs scripts/audit-xinyi-youbike.mjs`。完整結果與輸入雜湊見 [稽核資料](sources/youbike-placement-audit-20261027.json)。

## 驗證與限制

- 新增全部 129 站視角的實際繪製幾何邊界檢查，包含車柱、車輛及站牌；測試車柱在路外但車尾伸進車道、空柱預留、照片配置被新道路覆蓋及缺道路資料時均不生成錯置車列。
- 保留貼地、開關、距離節流、官方點位與 EOC 去重測試，加入持續整合檢查。
- 待驗證：實際遊戲 WebGL 外觀與效能、其餘 128 站連續近照／逐柱位置、路緣與入口邊界、現地尺寸。不得把模型道路零重疊宣稱為全區實景驗收。
