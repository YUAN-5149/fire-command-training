# 植栽樣式擴充（2026-10-27）

已完成：六種樹形（闊冠、展冠、直立、疏枝、寬冠、窄柱）及三種低矮灌木（低叢、扇展、直立叢），沿用 EZ-Tree 固定版本、MIT 葉片與 CC0 樹皮。新增形狀由原三種預設調整種子、比例、低分枝及枝葉數建立，非新增實際植物物種認定。

保留 528 個原有街樹錨點、補植樹錨點與應變中心 90 棵樹的位置。原九處植栽島內由 27 個簡單球狀灌木改為 45 叢葉片灌木，五叢交錯配置在各 2×1.7m 既有模型花床內；不擴大花床，不在道路、YouBike 停車柱或入口另撒植栽。原 GLB 其他綠籬保留。花床、植株尺寸與數量為示意，尚未現場量測。

三層幾何、批次實例、移動超過 4m 才重算清單、原有品質與顯示開關均保留。灌木低／中／高品質顯示範圍為 45／80／120m，六種樹與三種灌木共用兩張貼圖，幾何約 3.67MB。素材使用新目錄，避免舊頁面與新幾何快取混用。

驗證：九種模型幾何／索引／UV、三層細節、來源錨點、90 棵原樹替換、45 叢灌木局部邊界與不重複載入、品質開關、地坪更新及原應變中心配置回歸。

待驗證：遊戲實際 WebGL 外觀、樹葉遮擋與幀率；現場樹種、精確樹位尺寸及灌木數量。不得宣稱現況完全還原。
